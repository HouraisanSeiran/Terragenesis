# TD 同源地形保留与河床修复

本轮接续开发候选冻结之后的工作。原始 Terrain Diffusion 来源、固定种子和位置、宏观 512m / 局部切槽 4m 预算均不变；未训练模型、运行新 GPU 推理或接入 Minecraft。旧快照和失败结果保留。

## 已确认的原因与修改

原有限窗口目标把 TD 残差向窗口边缘衰减。在约 2.94km 的支持范围内，1000m 过渡带占去大部分内部，目标场本身形成方形低洼。后续固定宏观最陡下坡方向的约束又使地形出现平面与条带。原 seed29 普通河段的床面失败存在明确横断面矛盾，不是求解时间不足。

## 2026-10-14 本轮接续结果

v6 在 v5 的固定输入、边界、预算和断面约束上加入目标邻接梯度关系的 L1 保真项。真实 seed29 投影和独立冷审通过；输出 Laplacian RMS 为 6.89025m，原TD与目标均为 5.44505m，较 v5 输出 7.99193m 有改善，但仍有约 ±50–55m 的局部二阶缺陷，不能称为完全消除高频锯齿。

共享断面 v8 将原两侧30m witness 扩展为两个完整相邻、各不超过500m的 parent piece。原30m缺口的实际证书为0.049536m，已由完整支撑修正；但 v6 的4.04465km固定窗口在首次细床 LP 仍不可行，证据在 `verification/hydrological-planning-domain/naturalness-20261014-03/seed29-river-target-gradient/full-window-v8/generation.json`，不继承v4或v7的通过证书。

新增整边随形路径使用500m走廊和Dijkstra，先冻结完整路径身份及弧长，再允许窗口裁剪。seed3连续真实TD支持范围内只有一条完整同域粗边实际生成出候选路径；其首个含转弯的40m细床片仍因4m切深/连续底面物理约束不可行，证据在 `naturalness-20261014-03/seed3-frozen-terrain-path-bed-path-piece-v2/generation.json`。这表明随形路径已进入真实床面接口，但自然弯曲与床面预算还没有联合通过。

独立大范围预览使用seed3的5×5连续原生TD tile，38.40km×38.40km、30m原生采样，采用蓝—青—绿—黄—橙—红高程色带和固定阴影。原生路由候选保留21593个内部洼地终点、5116个未闭合边界终点和11个选中跨域冲突，图中没有把这些状态画成已认证河床。预览文件为 `verification/hydrological-planning-domain/large-td-preview-20261014-01/preview.html`、`full-region.png` 和 `central-zoom.png`。

新增三个显式可选入口，旧默认保持原行为：

- `finite-network-v3-channel-feasibility`：在宏观投影加入采样横断面规划包络，预先考虑 8m 河底、4m 切深和两岸高差。
- `finite-network-v4-harmonic-channel`：在相同包络下，用边界位移的离散调和延拓构造目标。两外行仍为冻结宏观高程；内部保留原 TD 起伏，叠加平滑的高程修正。
- `finite-network-v5-harmonic-channel-target-witness`：保留 v4 的全部输入和包络，仅将下坡见证改为优先选择目标地形更陡、且宏观高程严格下降的合法邻居；无合适邻居时回退原方向，固定出口不变。

横断面模块采用实际 1m fan4 三角面源高程的线性权重。它是**额外的采样规划要求**：区间消元与模块自己的断面模型等价，但任意采样点上的坡面上界可能强于细床求解器的顶点约束。因此 `fine_lp_necessary_condition=false`，通过它不意味着细床一定可行。河心最低条件的采样半径为 14.414m；坡面上界仅施于内侧 13.414m。支持外断面单独计数，不认作已完成。

| 调和目标 + 同一包络 | 349,656,269.57 m³ | 209.097 m | 通过 |

前两者使用相同原始 TD、固定界、归属、预算、宏观下坡见证和 21,238 行新增约束。调和目标方案的绝对改写体积减少约 35.2%。改变了目标场，不能称全部八个输入数组相同；对照工具明确记录七个共同输入和 `target_changed=true`。

上表前两项隔离目标构造变化；后两项隔离下坡见证变化。v5 与 v4 的八个输入数组逐值相同，绝对改写量进一步下降约 1.39%；核心目标高程未被投影修改的像素比例从 35.24% 升到 76.66%。这些是描述量，不是自然度通过门槛。

实际支持内有 274 个断面；完整 14.142km 粗边的另外 670 个采样断面在本窗口支持外。这些结果只认证局部投影，不认证整条粗边或全域接缝。各候选的 `cold-audit.json` 保留原始来源、固定界、实际 D8、归属、坡度、预算及新增断面残差检查。

原失败位置的三个固定点复核：仅加断面包络仍有 0.514m 的切深上下界冲突；调和目标方案消除了该三点冲突。随后**实际运行**原 node1 两侧各 30m 的细床生成并在新进程冷读，得到：

- 5,221 个顶点、10,152 个三角面；最大切深 1.767897m。
- 河心所穿三角面的下游纵坡、设计剖面、连续河心最低和两岸回接检查通过；外边界切深为零。
- 横断面最大残差约 2.65×10⁻¹¹m，连续底面残差约 9.58×10⁻¹¹m。
- 证据：`seed29-river-harmonic-channel/section60m/generation.json` 和 `cold-audit.json`。这是局部 60m 床面，不是完整窗口或整条流域的证书。

## 自然度与后续验收

主协调已查看同色阶高程图、固定光照阴影图和同标度坡度图。调和目标方案保留了更多原始脊谷，但仍有明显水平台阶、条带和长直河路，**自然度仍不通过**。固定 12 槽对照各保留 1 个本轮实际比较与 11 个未运行项，没有继承旧床面或湖泊证书。

随后实际查看 v5 图：v4 的大块水平台阶明显减少，原 TD 脊谷保留进一步改善；仍可见细栅格锯齿、高频纹理以及直线河路和局部平滑河谷。相对原 TD 的坡向余弦中位数由旧投影 0.270 提升到 0.968，四邻二阶差分相关由 0.132 提升到 0.579，但二阶差分 RMS 约 7.99m，高于原 TD 的 5.45m。这说明相关改善不能掩盖新增高频纹理，v5 也不授予自然度认证。

**v5 完整床验收实际拒绝。** 同一窗口原参数下，前 2/9 段成功并分别冷审通过，第 3 段 `piece-002-ce99d7a83014.json` 被原细床求解器判不可行，停止于首次失败。独立冷读终态为 `rejected_local_full_window`，完整接缝检查因覆盖不全而拒绝。前两段最大切深为 1.588518m 与 1.388979m，不能用这些局部值推断其余河段，也不能迁移 v4 的 708 个接缝样点通过结果。证据位于 `seed29-river-harmonic-channel-target-witness/full-window-v7/`。

对该真实失败请求进行了零 LP 诊断：104,806 行、28,027 个变量、439,390 个非零系数，包含两个实际共享截面。直接变量界及采用生产行容差 1e-8 的一次区间传播均未定位矛盾。零容差传播曾将约 1e-12 的共享截面重心系数放大成表面的 0.109375m 空区间，这不能作为物理不可行证书；其是否影响完整求解尚未查明。诊断与矩阵保存在 `full-window-v7/piece002-matrix-diagnosis/`。目前只能确认求解拒绝，不能断言该段一定需要超过4m切深；下一轮应检查共享截面数值与纵向/横向约束耦合。

**v4 完整固定窗口**的细床连接已按原生产流程单次生成，并在新进程独立冷读通过：9/9 段覆盖 4044.650788m，最大切深 3.706575m；8 处接缝的 708 个实际全宽分段点最大床高差约 1.65×10⁻¹⁰m。窗口宏观绝对改写量约 329,123,314.94m³，细床保守计入 49,366.75m³，合计约 329,172,681.69m³。窗口统计与上表包含计算 halo 的全支持体积口径不同。

完整窗口证据为 `seed29-river-harmonic-channel/full-window-v7/cold-audit.json`。本次调用原 `prepare_full_window_beds` 的 v7 共享断面流程，临时只读来源提供器返回已经校验的保存投影，没有重跑来源准备或宏观求解；调用方式及来源校验记录在 `provider.json`。覆盖仅为原粗边比例 `[0.357, 0.643]`，不能扩大到完整 14.142km 粗边。现行冻结包仍为开发候选，未升级成熟发布。

因此当前保留两种明确状态：v4 是该固定窗口的完整几何通过版本，形态仍有台阶；v5 是形态改善但完整几何失败的研究候选。下一步须处理地形细节保留与完整河床可行性之间的冲突，再扩展原固定多种子槽；不能把 v5 的外观与 v4 的床面拼成一份成功验收。
