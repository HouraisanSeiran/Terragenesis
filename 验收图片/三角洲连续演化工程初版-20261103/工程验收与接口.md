# 三角洲连续演化工程初版：主端交付

日期：2026-11-03。结论：**同源有限窗口的游戏用途演化闭环已验收并交付；自然形态、多级分汊和无限世界生产接线未验收。** Terra medium 实现，主端冷读数据、检查图片并验收。本次没有生成新 TD、扩大百公里范围或改默认世界。

图集与冻结存档：[交付入口](../../验收图片/三角洲连续演化工程初版-20261103/README.md)。

## 本轮实现了什么

统一海岸库存与最终床面 → 实际子格河床断面 → 准稳态流量与共享节点分流 → 有限输沙、冲淤和漫滩 → 潮滩及海洋搬运 → 口门随岸线延伸 → 满足真实水头与有限切沙的新汊启用 → 更新断面并继续演化。保存重载后可以接着推进，物理秒和等效年分别记账。

复用已有细河槽、河宽材料接口、有限床沙、Manning 水力、长期隐式海洋输运和物理潮浪模块。原细槽约18.24 km，另有实际河口连接；历史切槽归宿未知，未将其充作新来沙。断面宽度与100 m格宽分开，河道和外侧库存按面积分区，净床沙变化统一提交几何。

## 来源与情景

- 45×45 km，450×450格；计算格距100 m，原生 TD 30 m。数组[Z,X]，X向东、Z向南，格心原点(-19950,-19950)m。
- 正式来源 `window100-v2`，identity `778970b3c367bc5896e86e69b6eb17b30998482da96cd05d9d5ed7be796beb19`。原始 TD、地质基底、有效域及历史未知记录均保留。
- 沿用冻结历史基准种子20261020；并非按新正式世界种子20260903重建。新世界种子约定见根CONTRIBUTING.md。
- 历史600 m库存按面积守恒迁移，**历史形成过程没有在100 m重跑**。地质基底情景、历史床沙与本轮新供沙分开；新增陆地包含历史库存再搬运。
- Q=150 m³/s、固体输入0.08 m³/s、端口水位上限2.320855878 m均为明确情景，并非世界河网已知月来水。未知不补零。
- 形成阶段5等效年，0.25年形态步、4等权潮相、潮幅0.3 m；海洋沉降速度1e-5 m/s。随后两次25 h物理事件，潮幅0.3 m、浪高0.5 m、步长3600 s。完整配置见 `full-final-report.json`。

主端独立验收文件：`main-full-source-accept.json`、`main-full-routes-accept.json`、`main-full-hydraulics-accept.json`、`main-full-evolution-accept.json`。最后一项pass=true，检查共同床面、正水深、D4连续、共享节点流量、有限库存、来源、旧记录、时钟和预算。另从真实半年存档启用新汊后推进0.0625等效年，两路33.825／35.303 m³/s，固体残差1.19e-7 m³，证明新汊能参与后续年度反馈，见`main-full-active-continuation-probe.json`。

## 复用与续算

公开入口在`terrain_pipeline/coastal_delta_evolution.py`：`initialize`、`advance_years`、`advance_event`、`save`、`load`。`hydraulic_sections.nodes`为所有原／新河道断面的权威，`integrated.sections`仅兼容原始断面。输入ID须唯一；新参数、事件和结果另存。

```python
from terrain_pipeline.coastal_delta_evolution import load, advance_event, save
from terrain_pipeline.coastal_delta_hydraulics import HydraulicConfig
from terrain_pipeline.coastal_marine_sediment import MarineConfig

s, p = load("验收图片/三角洲连续演化工程初版-20261103/data/full-final-event2")
s, report = advance_event(
    s, p, 3600.,
    MarineConfig(step_s=3600., tide_amplitude_m=.3, wave_height_m=.5,
                 transport_rate_s=1e-6, entrainment_rate_s=1e-7,
                 settling_rate_s=1e-6),
    input_id="continuation-example-001",
    hydraulic_config=HydraulicConfig(2.320855878),
    inlet_solid_rate_m3_s=.08,
)
save(".scratch/my-delta-event3", s, report["updated_progress"])
```

这是继续计算示例，不在制图时执行。保存点已含继续演化状态，不必重新运行5年或启动TD。

**流程版本说明：** 正式案例先完成5年形成，再用修订helper在平均海位启用候选，最后重算两次物理事件。当前代码已将平均海位候选评估接到每个形态步末；从初始重跑可能提前启用新汊，不能承诺逐位复现本次5年过程。冻结存档、代码摘要和分步脚本保留实际过程；半年后的新汊年度续算已另验。旧低沉降率1e-9诊断不作为正式结果。

## 适用边界和下一步

本轮是有限窗口工程初版：矩形断面准稳态水力、统计潮相和规定海洋输运；漫滩为有限容量近似，物理事件末执行一次出岸交换，不是完整洪水过程。分叉后重汇合尚不支持。活动新汊来自地形约束候选及水头/淤积触发，不是无候选的自然拓扑生成。

主端已查看全域、河口、同址差值和剖面。**仍有明显D4直角、近平行长直河口段；分汊、沙洲和潮沟的自然形态不能判成熟。** 渲染没有补造叶瓣或加噪声掩盖。旧05任务要求的两个新叉和多级稳定平原尚未全部展示，继续列入[形态与多汊任务09](issues/09-morphology-and-multibranch.md)，不将本轮两条路线冒充恒河式成熟河网。

无限世界评价：E1有限450²窗口和米制口门搜索有明确工作域，但跨窗口上游依赖未接；E2来源/参数/存档可追溯，同种子整链乱序复跑未测；E3跨区域通量交接未测；E4库存守恒迁移已验，100/30 m嵌套通量未验；E5山体形态不适用；E6本窗口主河水沙几何相容通过；E7有限改道试算失败回滚通过，跨区编辑传播未测；E8交付体积见发布清单，峰值内存与规模增长未专测；E9存档冷读、来源和本模块续算通过，默认世界消费者未接。不能据本窗口声称无限世界生产后端完成。

后续先解决路线格向偏置和更多真实分汊、不同潮位下岛洲/潮沟形态，再考虑百公里材料与场地。默认世界、前端和500 km没有自动恢复；冰川实现前先与用户讨论。
