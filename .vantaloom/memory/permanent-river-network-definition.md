用户2026-11-04同意，永久河网按以下三层定义（详见 Terragenesis-1-3阶段科学评估与开源对照-20261104.md §11.6）：
1. 存在判据：Q̄·S^α ≥ C，并设最小汇水面积下限。Q̄ 是按固定气候基底算的长期平均流量（产流加权汇水面积）。目前产流系数为0.3，Q̄≈降水加权面积；第二阶段的G5/G11接回后换成真实产流。只依赖固定地形、固定图、固定种子气候，不随降雨事件变化。
2. 常年性（常年/间歇/季节性干河，参照NHD）是属性，不是判据；按枯季流量或基流判定，G5/G11接入前标「待定」。
3. 允许下游流量减少：Q̄ 低于阈值处河道结束，形成内陆终点，不默认通到海。
单次事件流量只决定水深、河宽和湿润范围；河宽、水深、Strahler分级作为属性另存。α 和 C 要在固定种子窗口上试算，并做原生形状保真对照。现有 native-event 的 channel_mask 保留为事件展示层。气候参数修订后要另出河网版本，不覆盖旧版。
