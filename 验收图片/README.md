## 范围与使用

包含历史试验、失败对照、已被后续版本替代的过程图；归档不代表这些结果全部通过验收。具体结论以来源目录中的验收报告为准，不能仅凭图片文件名判断完成状态。

不收集原始 DEM/TIFF、参考素材、第三方依赖库图片、游戏资源或另一工作树中的副本。四个来源目录内的排除项目见 `排除清单.csv`；工程的 `data/`、`research/`、`.claude/worktrees/` 不在归档来源内。

`图片清单.csv` 记录每张图片的原始相对路径、归档相对路径、字节数、原文件修改时间及 SHA-256。复制时逐张比较原图与副本的 SHA-256。本目录是本次整理的快照，后续新生成的图片不会自动同步。

四阶段计算进度本轮未改变：宏观基底 → TD 地形合成 → 汇流与盆地分析 → 河湖及必要高程调整。本轮仅整理已有图片，不重新生成地形，不改变验收结论。
