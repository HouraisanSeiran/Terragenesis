# 同源 TD 河网：流量、岩性与河槽宽深

2026-10-15 完成本轮生成规则、数字产物与图审。两名 GPT-6.1 Sol medium 子代理分别实现核心与验收工具，主协调代码审查、运行和图审。使用既有38.4×38.4km、1280²、30m、seed3低地河网；没有重推TD、修改接收图或接入Minecraft。

## 生成规则

代表性流量直接使用来源 `mean_routed_q_m3_s`：第3个合成年各月出流体积总和除以全年秒数。支流汇入已经反映在该字段，不能再重复累加。短时暴雨不直接重塑永久河槽。

定义流量比 q=Q/(1m³/s)、河床硬度 Hb、河岸硬度 Ha（均为0–1）。默认生成暴露量E=3，无量纲，系数f=1−exp(−E)：

- 顶宽 W=f×min(120m, 4m×q^0.45×(1+1.5Hb)×(0.5+1.5(1−Ha)))。
- 切深 D=f×min(4m, 0.6m×q^0.3×(0.4+1.2(1−Hb))×(0.8+0.4Ha))。
- 梯形底宽为顶宽的60%，两侧线性接回；零流量或零暴露量不切削。

同材料下流量越大，宽深非减；硬床软岸偏展宽，软床偏下切，硬岸抑制展宽。硬度场由世界种子和绝对位置的连续噪声确定，尺度6000/1800/600m、权重0.6/0.3/0.1，床岸分别取不同盐值。不以图幅归一化，重叠位置一致。它是虚拟材料场，不是从TD训练或识别出的实测岩性。参数是生成规则，不是侵蚀速率或实际演化年数。

这里的深度是相对原TD的切深，**不是水深**；宽度是河槽顶宽，也不是已经求解的瞬时水面宽。湿地、浅湖保护区仍保留设计宽深，实际切削置零，避免主干宽度人为归零。粗栅格投影采用最近可切削河道格的断面；完整细尺度连续床面及水力重算尚未接通。

## 三角洲讨论起点（未实施）

既有 `metric_delta.py` 提供有限范围沉积和分汊候选；`metric_delta_sediment_product.py` 可核对上游水沙出口来源。现有候选仍不认证自然海口，也未实现完整动态分汊。

建议首版先做河流主导三角洲：确认海洋连通水体及海底地形，接入明确时间窗的水量和固体泥沙输入，以输沙能力降低决定沉积；河口沙坝抬升后再生成有流量分配的分汊，重新核对局部水沙账。首版海面可固定，波浪/潮汐作为后续类型控制；不是每个海口都强制生成三角洲。

三角洲作为上游规划域末端的有界子域，输入冻结、范围与演化步数设预算，越界泥沙明确计为域外输出，避免反向触发无限流域重算。河床粗栅格挖方不可直接等同河口输沙。首版类型和水沙接口待与用户讨论确定。
