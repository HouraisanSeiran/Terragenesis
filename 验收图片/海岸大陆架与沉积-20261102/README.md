# 海岸大陆架与有限沉积

本目录展示同一 TD／板块来源上的已验收海洋基底和简化沉积接口；三角洲阶段仍在进行。两图均为保存数据的只读重绘，地形颜色与阴影不代表卫星观测或植被。灰色表示未知、封闭负高程或无效区域。

- **01 海岸大陆架同源对照**：相同坐标与色阶对比原始同源床面和 v2 派生基底。陆架宽度是 18–55 km 的模型目标范围，不是实测坡折；模型对海底的构造／地形映射不是河流供沙。
- **02 河口有限沉积**：在调查河口海格，显示 100800 秒（约 2.25 个潮周期）后的床面变化和剩余移动固体。床变单位为毫米，不是成熟沙洲；移动库存色图隐藏小于 0.1 立方米／格的值。

沉积使用明确假设：流量 150 m³/s、断面 100×3 m、固体／水体积比 0.0005；当地真实水沙观测未知。输入固体 7560 m³，其中床面 2783.858 m³、移动库存 4776.142 m³。此有限情景不能代表长期沉积。

世界种子 20261020，原始 TD 间距 30 m，本图及模拟网格 600 m；图像像素不提高地形精度。世界 X 向东、Z 向南，坐标单位为千米。完整 TD 页来源、摘要、参数与每图覆盖状态见 `manifest.json`。
