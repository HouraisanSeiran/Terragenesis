# 实现状态：直接 VDM 扩散研发中（2026-09-27）

最新路线：**条件扩散直接输出基础 XYZ VDM → 独立特殊地貌算法 → 体素化 → Minecraft**。

- `vdm_diffusion/` 已实现三通道 U-Net、DDPM 训练、DDIM 采样、权重保存、VDM/OBJ 导出和独立悬崖算子。
- `diffusion/` 已接入固定版本 Terrain Diffusion 高度/气候模型，作为条件来源；它本身不输出 VDM。
- Java `vdm/` 实现三方向位移图、文件读取、折叠表面体素化和有限地图接入。存档记录模型与 VDM 身份。
- Python 9项测试通过；Java 历史原型21,794项、扩散协议与VDM几何及Python/Java交叉格式739项断言通过。
- RTX 2080 SUPER / CUDA上完成32步合成训练、16步直接XYZ采样及悬崖导出。短训位移量严重失真，明确未通过地形质量评估。
- 自研VDM所需PyTorch/CUDA已安装并验证。上游Terrain Diffusion权重已下载，但其额外依赖安装被主动中止（下载慢且非直接VDM验证必需）；其原始高度推理尚未实测。运行 `tools/setup_diffusion.py` 可继续安装。
- `verification/vdm-smoke/` 是合成数据训练及导出的执行检查，**不是自然地形效果或可用预训练权重**。
- 尚无真实三维地形数据训练后的 VDM 权重。无限分块与接缝约束尚未实现，当前 Java 桥接只读取有限 VDM 文件，越界会报错。
- 当前0.2.0是研究构建，**不是可以正常探索的成品生成器**。四种地貌算法组合、差异侵蚀和洞穴水系尚待完成。
