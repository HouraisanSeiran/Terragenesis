# 长垣地形研究资料

本轮重点：**先由真正的扩散模型生成基础地形，再用地貌条件、水文侵蚀、导数／向量场和三维表示控制与完善结果。**

1. [地形算法与数学方法调研](地形算法与数学方法调研.md)：生成模型、程序化辅助、水文侵蚀、三维地形及四种地貌的选择建议。
2. [数学工具箱](数学工具箱.md)：梯度、Hessian、Poisson、向量场、Jacobian、SDF、守恒方程及数值求解。
3. [扩散基础架构](扩散基础架构.md)：数据流、模块职责、实验计划和验收标准。
4. [资料索引](资料索引.md)：53 项公开资料请求，47 项成功保存，6 项不可用，逐项可追溯。

`sources.json` 保存来源、获取时间、状态和哈希；`sources/` 保存资料副本。论文全文、项目文档、源码和题录的证据强度不同，正文已区分。
