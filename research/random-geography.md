# 按种子生成 Terrain Diffusion 地理条件

当前 `geographic_v1` 使用世界种子和绝对坐标产生模型已有的五通道条件。粗网格每格对应 256 个模型原生像素；在当前每像素 2 个本地方块、世界 3 倍尺度下，约为 1536 个世界方块。窗口从任意坐标开始采样时得到同一个连续场，种子 0 有明确结果。

| 通道 | 单位 | 当前生成依据 |
| --- | --- | --- |
| 高程 | 米，海平面为 0 | 多尺度平滑值噪声确定海陆和起伏，海岸附近细节渐隐 |
| 年均温 | 摄氏度 | 纬向周期变化、局部扰动和海拔递减 |
| 温度季节性 | 摄氏度乘 100 | 大陆性、纬度变化 |
| 年降水 | 毫米/年 | 大尺度湿度、海洋邻近、简化迎风增雨和背风减雨 |
| 降水变异 | 百分比 | 大陆性和局部扰动 |

此处的地理条件是一套简化的随机约束，不是实测大陆、构造运动或完整水循环。它不读取 WorldClim、ETOPO 或上游统计缓存；Terrain Diffusion 模型仍负责生成最终基础地形。对同一个世界种子，新模式与旧 `legacy_worldclim` 使用不同生成身份和缓存。修改本地条件算法时，条件源文件哈希也进入身份。

上游 `frequency_mult` 和 `drop_water_pct` 参数仅为接口兼容而接收既有默认值；本模式使用固定 v1 空间尺度，海陆比例由种子决定。传入其他参数值会报错。

运行 `tools/preview_geography.py` 可生成 `preview/geography/conditioning.png` 检查五通道范围；`tests/test_geography.py` 检查种子、边界拼接、单位、海岸连续性和绕过上游外部数据读取。模型对高程条件的响应强度仍需通过真实推理样片评估，不能把条件图当作最终方块高程。
