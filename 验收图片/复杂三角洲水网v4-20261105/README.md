# 复杂三角洲水网 v4 图包（2026-11-05）

验收基准：`.scratch/delta-network-v1-20261105/reference/` 的 ref2（平原分汊网络）与 ref3（小型河口沙洲与前缘）。全部 CPU 计算（numpy/scipy/skimage），地形只读已保存的 `terrain-v3/` npy。

## 版本演进
- v1：规划树式分汊，汊道平行、环少。
- v2：递归分汊+汇合骨架（允许入度>1），旧 PlanConfig 硬限制改为尺度软约束。
- v3：斜向随机连接汊、曲流、扇面软拉回、形态闭运算、碎块淹没、岛屿连通硬检查。初审未通过（圆水塘、前缘鸟足、浅滩描边、上游残线、沙洲太少）。
- v4：骨架沿用 v3（同种子同图），只重做造地：沙裙（相邻口门供沙叠加成跨汊沙坪）、岸边沙带、老叶瓣沙边、封闭水洞全部填平、上游随机潮沟删除并把主干延伸到窗口边缘、浅滩坡度随供沙量与对数正态噪声变化。新增产物 `sand_mask.npy`。
