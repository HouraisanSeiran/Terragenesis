# 活动分流与水沙续交

第三支淤堵后实际分配流量归零，900m³/s沿共享分叉进入第一支；其他三支保持原份额。末态1440/510/0/510/540m³/s，四条活动路线具独立外海口，关闭路线保留为历史水道。

蓝线为活动河网，红虚线为关闭路线，数字单位m³/s。地形配色不代表植被，计算600m、TD原生30m，线宽不是真实河宽；所有强迫为工程情景。图左10等效年状态，右90000s事件后，X东/Z南向下。

14.4万m³有限输入中，5.184万m³先保留为上游待交付，随后显式送回原入口库存；原来源只记一次，保存重载/禁止重放/收支检查通过。续交是入口库存操作，不能称为已输到海口。原TD/base不变。

验收与来源见报告、manifest及数据快照。23项相关测试通过。此为活动分流和接口机制验收；稳定潮滩、分汊间平原及完整三角洲形态仍待完成，百公里不启动。默认世界未接入。
