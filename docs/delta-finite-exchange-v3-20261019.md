# 有限床沙交换、湿岸侧移与薄水床载修复 v3/v4

2026-10-19：已实现床沙再悬浮、受水流剪切抑制的沉降、湿岸保守侧移，以及携带完整水沙状态的连续运行。旧 v1/v2 数值实现和旧产物保留。完整自然三角洲的形态验收仍未通过。

## 本轮实际修改

- `terrain_pipeline/surface_rivers/metric_fv_exchange_v3.py`：以实际水深、动量、Manning 床面剪切及 Airy 波浪相位计算输沙平衡浓度；起沙同时受速率、有限床料库存与水体浓度容量限制。起沙从床面扣除并等量进入悬沙。湿岸超坡输运只在至少一侧有水的内部格面发生，不扩散整片干陆地。
- `terrain_pipeline/surface_rivers/metric_fv_growth_coupling_v3.py`：水流、MPM 床沙、湿岸侧移、悬沙平流、净沉降、再起沙依次更新。沉降趋向当前剪切对应的平衡浓度，不再在高速水流中无条件沉降。更新床面与过水高程后，下段继续求解水流。
- `tools/run_natural_fv_growth_interval_v3.py` 与 `tools/run_natural_fv_growth_v3.py`：保存新增起沙逐格量、侧移逐面量、参数身份和有限源游标。允许核验旧 v2 依赖后原样迁移状态；失败块整块回退，减小物理时间步，不重复消费来源。
- `tools/inspect_natural_fv_growth.py`：独立核对新增交换项对床面和悬沙的影响，缺失新字段不得通过 v3 检查。

公式、单位和默认参数见[机制规格](../verification/fluvial-delta/fv-growth-v3-mechanisms-20261019.md)。新平衡浓度与岸坡迁移率是明确声明的经验参数；未声称完成黏性岸坡、波浪辐射应力或实地标定。

## 潮浪与湿岸联合运行

从 120 秒末态继续：有限供沙游标顺接，湿岸临界坡设为 0.05m/m，代表较易移动的松散饱和岸滩；默认 0.35m/m 在该父床不会触发侧移。潮幅 0.3m、周期 1200s，从平均海位涨起；波高 0.3m、周期 5s。潮周期为压缩机制情景，非真实半日潮标定。

原计划 600 秒，实际完整提交 112 秒后停止。随后 0.125s 与 0.0625s 的 MPM 步分别请求约 2.003cm 和 1.036cm 最大床变，超过保持不变的 1cm 上限。末检查点 `checkpoint-0000576.npz` 为物理时刻 2940s、来源游标 65468s。拒绝块不消费新来源。本次不是完成 600 秒或完整潮周期。

## v4 已实现的负责层修复

新增 `metric_fv_bedload_v4.py`，保留 MPM 请求并限制实际接受量，随后照常进行供沙格库存限制、海侧输出与床面更新。逐面保存请求、载流容量、实际接受量；每个区间的容量/方向违规最大值和绝对累计通过量保存到块账，避免往返抵消掩盖超限。

`metric_fv_growth_coupling_v4.py` 和 `tools/run_natural_fv_growth_v4.py` 复用既有水沙顺序和事务调度，通过私有函数绑定接入新床载与加速波场，不修改旧模块的全局函数。发布检查点及总结使用 v4 身份；旧 v3 检查点核验后原样继承床/floor、水深、动量、悬沙及有限源游标。加速波场同时作用于床载和再悬浮计算。

31 项聚焦测试通过，包括上文 11 项、16 项波场等价测试及 4 项 v4 床载/实际运行测试。真实拒绝面的原请求约 0.1683m³ 保留，实际接受约 1.55×10⁻⁶m³ 固体；正常深水面在容量未触发时与原 MPM 结果一致。

完整格网 0.25 秒短验通过，最大净床变 0.000775m；独立水账余差 1.39×10⁻¹²m³、固体余差 4.12×10⁻¹¹m³，逐格及载流容量/方向检查通过。短验在独立分支，后续主链从 v3 的 112 秒检查点续接，不重复消费短验来源。[短验核对](../verification/fluvial-delta/natural-fv-v4-carrier-smoke-audit-20261019-01/audit.json)。
