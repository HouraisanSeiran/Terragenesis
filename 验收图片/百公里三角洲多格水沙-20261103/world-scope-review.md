# 百公里三角洲：无限世界标准逐项登记

范围为单个确定来源的359×564、600m计算域，历史种子20261020。依据根《无限世界地形生成评价标准》。本案例不是无限生成或全球30m的验收。

| 项目 | 状态及证据 |
| --- | --- |
| E1 有限依赖 | 有限域支持；每次依赖已准备陆架窗口、完整河网与库存，图和数组上界明确。跨世界窗口自动调度未测，不能只按点查询隐式重算全域。 |
| E2 确定性 | 保存冷读续算与输入ID去重测试通过；河线用既有固定种子的非规则路径。不同窗口大小/乱序准备的百公里等价性未测。 |
| E3 跨区连续 | 原TD及板块来源链保留；本次是单窗求解，跨窗水沙边界和河口独占归属未验。 |
| E4 多尺度 | 600m格平均床与多格细断面分别保存；实际XZ保留。没有把插值当30m新增细节；600→100→30m共享库存与河网细化尚未验。 |
| E5 形态 | 实际厚沉积体达到百公里，出露块/水下体分别统计。平原平滑、部分长直河段、格向岸线及材料均质仍是限制；自然美学验收留给用户。 |
| E6 水文地貌 | 同床、多格库存、水力和潮浪已接线。主端发现中心格接海误判并要求补齐足迹接海；最终以main-final-accept.json为准。上游Q15000及固体20m³/s为声明情景，不能称已接真实该流域。 |
| E7 有限重算 | 原始TD、原陆地基底与历史产物独立，参数改变生成独立派生产品。本次整窗计算，未证实局部编辑仅影响局部邻域。 |
| E8 资源 | 首轮25h事件单次调用耗时354.91s、终点RSS87.36MB，不是峰值；计算无GPU。最终事件成本另见报告。600m预算不能推断全域30m成本。 |
| E9 可消费 | NPZ/JSON配对来源、坐标、物理秒/等效年、唯一输入及水沙账；冷读/续算测试通过，逐图来源hash。局部DEM及河槽接口见interface-handoff.md，默认世界/前端未接。 |

地质构造1125等效年对数值混合强度敏感，同供沙125年350→700 sweep新陆面积约增加75%。该时间仅为构造参数，不能作物理年代或稳定性证明。事件继承已分配真实库存，未分配量不参与后续供沙。短潮浪验证不证明千年稳定。
