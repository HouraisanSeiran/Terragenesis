# 隔离的历史算法源码

本目录执行用户选择的A方案：活跃代码逐步收敛到最新实现，旧算法按模块族隔离，保留明确的历史复验能力。本目录不是默认生成后端，不在默认Python搜索路径中；禁止在生产入口自动遍历、导入或fallback到这里。

## 归档纪律

1. 每族在修改前复制原文件字节，保留原相对路径、SHA256及明确的归档范围。不把并行修改期间的全仓复制冒称同一时刻基线。
2. 可信边界必须在归档之外固定：显式历史适配器固定manifest或每文件预期SHA，再检查归档字节。源码和manifest同时改写也必须拒绝，不能只相信随包提供的哈希。
3. 旧schema验证器继续验证旧包，不能把旧数据换标签交给新schema。共享参数/坐标/数值辅助职责迁入无版本common模块，保持当前调用者一致类型。
4. 历史生成/读取/恢复只能通过明确命名的legacy命令或适配器进入；默认新生成使用已迁移最新版。不得用旧模块名的透明代理伪装“只留最新版”。
5. 历史结果与verification/不改写，不删除hash校验、不用更新旧hash掩盖实现变化。遇到硬pin依赖时先迁移读取路径或增加受控快照策略。
6. 不自动执行任意归档文件；历史适配器只加载allowlist中的固定文件，验证路径边界和SHA。回归必须覆盖实际旧算法小例、最新正常调用和篡改拒绝，不能只测试能import。
7. 单族完成不表示全仓收敛完成。尚在活跃路径中的旧共享内核、profile或codec继续登记在迁移清单中，不能改名后宣称删除。
