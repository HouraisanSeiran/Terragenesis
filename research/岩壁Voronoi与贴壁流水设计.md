# 岩壁 Voronoi 与贴壁流水设计

日期：2026-09-27。状态：**设计提案，尚未接入模组**。当前实际悬崖仍为 CliffSculptor 的 tanh 陡坎及侧向 VDM 位移。

## 1. 用户提出的路线

Terrain Diffusion（或未来可替换的基础生成器）→ 选择岩壁区域 → 生成倾角可控的岩壁骨架 → Voronoi 岩块、节理及耐蚀度 → 局部三维表面的贴壁流水与侧蚀 → 写回 VDM → 必要的体积掏蚀、失稳与沉积 → Minecraft 方块。

Voronoi 用于特殊地貌后处理，不替换已约定的扩散基础地形。不同职责分别实现，不继续往 CliffSculptor 单类堆积功能。

## 2. Voronoi 用法

首版可以在岩壁局部坐标中生成非均匀、方向可控的 Voronoi 单元，给每块设置不同的浅层退缩、朝向扰动和岩石耐蚀度；边界提供更易侵蚀的节理场。仅有 Voronoi 分区没有三维几何，仍需通过深度、块面或位移将其转成岩壁。

避免将所有单元边界挖成等宽等深沟槽。建议大块与小块混合、按岩层拉伸、部分边界不出露，并对边界位置作有限扰动。不能假定后续侵蚀必然消除蜂窝感。

跨多个岩壁面片时，应使用世界坐标中的 3D 材质/裂隙场或共享边界数据，以避免岩层与裂缝在接缝处跳变。2D 局部 Voronoi 可先用于独立样片验证。

## 3. 将岩壁当作斜面求解

可以使用局部 (u,v) 网格，但计算必须基于变形后真实三维位置 P(u,v)。v 向下只是索引约定，不能直接把普通高度图的值解释成世界高度，也不能忽略网格的实际长度、面积和倾斜。

令 n 为实际表面的单位外法线，g 为世界重力，沿面重力为：

g_t = g - (g·n)n

可先实现有重力偏向的表面输水模型：崖顶给定来水，水向较低的相邻表面单元分配，并沿低凹沟槽汇流。水量更新使用真实边长、面面积和通量，记录进入、流出、蒸发/入渗及滞留的水量。变形较强时，应通过局部切向基或曲面度量把三维速度换成 UV 速度。

“每一步都只能向下”可以作为视觉原型的简化约束，但不是完整水动力学。保留横向运动及平台上的积水/溢流；不要直接把所有水滴 XZ 坐标锁死。真实惯性、回流与局部上行不包含在首版下坡近似内。

悬挑底面和凸缘不能无限强制贴壁。需要明确近似的脱离条件，把不能保持接触的水转为离壁下落，并将再次碰撞的水量交给下方表面。此过程是游戏视觉近似，不宣称求解了接触角、表面张力或完整薄膜流体。

## 4. 只提取岩壁，保留边界条件

无需将整个世界还原成三维网格。提取岩壁面片和一圈几何过渡区，但同时提供：

- 崖顶的入流位置、流量和可选输沙量；上游汇水可由更大范围的二维水文缓存计算。
- 侧边与邻接面片的通量交换；同一边只结算一次。
- 崖脚的出水、输沙和沉积接收区。
- 固定或共享的接缝顶点及足够几何缓冲。

不能把现有 HALO=16 当成对任意水系都足够的范围。它仅服务于当前有限横向位移；上游汇水域可能远大于此。模拟按世界坐标锚定的岩壁块运行并缓存，不能让各 Minecraft 区块独立重复侵蚀边缘。

## 5. 贴壁水与横向侵蚀

必须区分两个方向：

1. 水沿岩壁切平面向下、向侧方流动。
2. 岩石沿表面内法线退缩，沟槽侧壁也可被侵蚀。

局部退缩速度 E 可以由接触水量、沿面速度、岩石耐蚀度、裂隙和侵蚀阈值控制。对于保持对应关系的顶点，简化几何更新是 D_new = D_old - dt E n；它本身不是完整侵蚀模型，E 的计算与水沙质量收支需单独定义。

侧蚀不能靠随机增减 XZ 冒充。对与水接触的沟槽两侧和弱岩层计算退缩，可形成槽壁扩宽、软层凹槽和崖脚掏蚀。薄水膜不自动获得任意强度的岩石侵蚀能力；流水冲刷、含沙磨蚀和岩石溶解应作为可分离的过程与参数。

VDM 适合保持表面拓扑的变形。若产生穿孔、分离岩块、洞穴连通或无支撑悬块，转交局部体积/密度表示和支撑检查，不能只推顶点后假装拓扑已正确更新。

## 6. 倾角小于 90°：同时指定倾角和方向

仅有“与地面夹角小于 90°”不能区分普通斜坡与向外悬挑。定义：

- alpha：岩壁基准面与水平面的锐角，0 < alpha <= 90°。
- sigma：+1 为上部向岩体外侧伸出，-1 为上部向山体内侧退回。
- H：垂直高度；t∈[0,1] 从崖脚到崖顶；C(u) 为崖脚线；e_out 为水平向外方向。

基准面：P0(u,t) = C(u) + t H e_y + sigma t H cot(alpha) e_out。

再叠加沿基准面法线的 Voronoi 岩块与侵蚀深度，得到 P；输出 VDM 为 P - P_reference。正式实现仍需明确局部面片与现有世界平面参考网格的映射与接缝。

例：H=40 方块、alpha=60°，崖顶相对崖脚的水平偏移约为 23.1 方块。向山体内偏是普通斜坡，向外偏是悬挑。alpha=90° 时偏移为 0，是垂直壁。趋近 0° 时占地会发散，必须有最小倾角、占地上限及与周围地形的相交检查。

## 7. 拟议模块与验收

以下名称为建议职责，并非已存在的实现：

| 模块 | 职责 |
|---|---|
| CliffPatch | 崖脚线、倾角、倾斜方向、面片采样与边界 |
| VoronoiRockField | 岩块、节理与耐蚀度；可供多个面片共享 |
| SurfaceRunoffSolver | 沿面水流、入流/出流、积水和水量守恒 |
| CliffErosionSolver | 接触侵蚀、侧蚀、输沙与退缩量 |
| WaterDetachment | 离壁下落、重新接触与边界输水 |
| CliffVdmWriter | 顶点对应、VDM 写回及接缝验证 |
| RockSupport | 局部体积连通、崩塌与沉积；后续阶段 |

首版预览顺序：规则基准面 → Voronoi 岩块 → 流水路径/流量 → 侵蚀后几何；对比垂直、向内倾斜、向外悬挑三种方向。检查固定种子重现、水/沙收支、单步退缩上限、网格退化/自交、边界连续和局部缓存一致性。尚未实现之前不得更新模组效果声明。
