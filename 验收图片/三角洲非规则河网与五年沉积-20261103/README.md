输入情景Q150m³/s、固体0.08m³/s，实际流量受到原端口水头限制；未交付部分继续留账。五年输入固体12,623,040m³，待交付约10,371,448m³，不能把整份情景供沙当成已入海。最终事件的逐口gross过沙量包含历史库存再搬运，不与外部新供沙重复相加。

年度和物理时钟分开：不是连续五年逐小时潮汐水动力。相同0.05年案例中18天单步与日步的总沉积量相差约19%；这份成果采用游戏用途近似，未做现实参数校准或网格收敛。200m演化网格不能表示30m细沙坝；图像上采样不增加地形精度。

## 仍待完成

清晰的口门沉积叶瓣、沙坝引导的持续多级分汊及更大尺度形态验收仍需改进。下一步应基于已有输沙粒级/沉降和搬运模块约束河口沉积集中程度，并核对长期河道淤积与输沙能力的平衡；不通过抬高水头、重复加沙或人为画出扇形完成形态。默认世界、前端和500km扩域未接入本实验。

使用实际历史种子20261020，不改为新世界种子。原TD和旧图集保留。此次后四年计算约299秒，最后25h事件约33秒，过程采样峰值工作集约510MiB；图集只复制一个最终存档，其余阶段链接原文件，避免重复占用磁盘。
