# 地形约束三角洲 v5

2026-11-08。依用户两张参考图，取消数圆拼接与口外延长，以继承低地、湾内填积、山丘和未填海湾组织整片平原。绿为高程配色，未计算植被；图中平原是地质构造初态，物理600秒另计。

![基准形态](base-main.png)

基准最大连续平原267.03 km²，原口左右宽7.15／3.25 km，12个几何口门、5环。100 m源地形；历史v4为另一选址，各产品的同源差分才可作配准前后比较。[同坐标源与改写](base-source-and-change.png)。

![百公里平原](hundred-km-overview.png)

最大连续平原1874.79 km²，距边缘至少2 km的连续内部47.4×100.3 km。百公里是平原跨度；4个口门沿岸只跨24.57 km。整体平原上游及沿岸触窗，核心不触窗。[100 m局部](hundred-km-detail-100m.png) · [原TD及构造高程差](hundred-km-source-construction.png)。

百公里情景声明5760亿m³地质固体供给，海侧正填积中位约440 m、最大约1410 m，未标定地质年代；属于规模与接线案例，不据此认定现实形成自然度通过。局部和高程差图已只读重绘，分别纠正旧图偏海裁剪和±30 m饱和色阶。

![600秒实际床变](physical-bed-change-600s.png)

两例分别以Q8000／30000 m³/s运行600秒。固体账差均0，300＋冷读＋300秒与连续运行逐位一致；约83／199秒完成含重复续算验证的全流程。渠道外湿格最大床升6.46／0.144毫米，是水下沉积证据，不解释为新沙洲。

原生TD为冻结30 m来源（种子20261020），新算法种子20260903。主图为保存DEM与水体的地形配色，100 m重采样；没有生成式图片、遥感光谱或植被分类。构造和事件数组、代码身份、来源摘要、图像摘要详见同目录manifest。

这版仍为工程近似：潮流反转、长期漫滩和迁汊塑形未接，百公里海岸仍较光顺；30 m重算有岸边切山和拓扑变化，保留诊断，未声明多尺度一致。
