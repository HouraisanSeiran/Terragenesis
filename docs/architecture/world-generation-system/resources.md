源码模块与运行依赖分开登记：`runtime` 是执行环境，`models` 是原始模型权重，`vendor`/`third_party` 是外部实现；它们通过既有适配器使用，不能计成自研算法，也不因本次清理而删除。

现有 `algorithm/manifest.json`、`minecraft-mod/manifest.json`、`river-system/*/README.md` 继续作为逻辑边界说明，分类不移动其中任何代码。

`legacy-code`、`backups`、`.claude/worktrees`、`service-0.9.0` 是历史/其他checkout，不纳入当前一方模块总数。显式legacy工具仍登记；冻结实现保持可复验，不自动回接主线。

根目录 `temp_*.py` 与 `.scratch` 中实验/执行脚本作为工作记录保留，不将其自动认证为可用生产模块。
