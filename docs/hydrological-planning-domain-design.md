# 水文规划域首版设计

用户已在Q1–Q17讨论后确认实施。本文件记录已确认的设计；实现和验收状态见[任务规格](../.scratch/hydrological-planning-domain/spec.md)。设计确认不等于算法已完成。

## 世界与水文组织

以米制坐标表达数百公里、尺度可调的河流。宏观地形与水文共同规划，允许改变派生大陆、山系和盆地布局，使有限流域可成立；原始TD数据保留。宏观规划单元采用有限最大范围、有限邻域和有限调整次数；内部水文规划域围绕完整水系及共享分水岭确定唯一归属。

宏观单元是计算组织，不是板块模型。规则存储边界不能直接当分水岭，禁止用标签截河、狭窄高墙或到处环形围山伪造隔离。单元间共享边界必须由确定性规则共同确定，不能由首次生成顺序决定。目标河长与流域最大跨度分开配置，不保证每条河达到目标长度。

先冻结宏观排水骨架、合法终点、共享边界和归属，再进行详细生成。先前已确认的域间不交换河水、共享分水岭及有限重算原则继续有效。明确终点以真实海岸或可平衡内流盆地成立，未知窗口外部不视作海洋。

## 首版交付

自动生成两个相邻完整域，共享一段山脊：一侧通海，一侧进入内陆湖。允许选择合适开发种子，不手工绘制答案边界和河网。全域粗规划确定地形骨架、干支流连接、汇水和水量；关键位置再生成真实TD派生精细地形与河床。可视化明确区分全域粗成果与局部精细验收，不以局部图像冒充全域精细完成。

宏观谷地塑形与局部河槽分账：宏观修改有高度、面积和总变化预算，局部河槽保留4m切深上限；同时记录最终地形相对原始TD的变化，避免通过宏观步骤隐性突破开挖解释。先标定、再冻结预算进行验收。失败可按固定次数更换候选；仍失败保留拒绝，不无限扩域或临时抬预算。

季节气候依种子和坐标生成，12个月逐年重复。固定河床、湖盆和分水岭，计算产流、蒸发、蓄水及合法出流；湖面积随水位变化。年度循环须实际收敛，不能通过夹水位、丢弃水量或未定义的地下漏水制造平衡。溢流必须有域内合法下游，否则当前内流候选失败。

资源提供节省、均衡、优先速度档位及可选上限，改变调度、缓存和提前准备，不改变最终成果与精度。允许首次进入未准备范围等待，已交付地形不能因为后来补齐远端汇水而悄悄重塑。

## 验收

1. 归属无重叠、无遗漏，查询邻域/候选次数/工作量有上界；保留预算不足或不能成立的失败案例。
2. 共享边界最终地形排水相容，无跨域串流；改变准备顺序不改成果；域内编辑不修改邻域或共享边界。
3. 真实海岸出口、内流湖年度水量与收敛；不将规划级水账称为全网水动力。
4. 共享山脊、普通河段、汇流口、海口和湖岸的真实TD派生几何、修改量、河床与图审。保持来源身份，预算冻结后独立验收。

只做上述关键验收及受影响的必要回归，不反复重跑无关测试。分区算法、TD宏观响应、数值预算由工程调查和小范围实验确定，不能把候选参数当成已验证默认值。

地下连接先限域内。跨域连接已登记[后续任务](../.scratch/hydrological-planning-domain/issues/01-future-cross-domain-underground.md)，须另定水头/地质、配对水账、有限依赖和独立性变化条件，不自动解除现行跨域禁令。
