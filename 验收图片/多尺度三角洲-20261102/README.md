# 多尺度沿岸三角洲候选：约 45、114、255 km

[三组对比](三组对比.png) · [45 km 地形图](45km-地形图.png) · [114 km 地形图](114km-地形图.png) · [255 km 地形图](255km-地形图.png)

这三张是已保存的 TD 派生地形配色与初始河道中心线，方向、坐标和比例尺见各图；对比图各栏比例不同。它们呈受陡峭大陆边缘限制的细长沿岸复合三角洲和沉积平原。255 km 是较长轴的实测跨度，东端有较直的半径边界；不能据此称其为宽 255 km 的三角洲或恒河式宽扇。目录中 `40/120/300` 是历史目标，标题使用实际约 45/114/255 km。

陆地面积与跨度来自连通沉积地貌而非画布。距沉积地貌边缘至少 2 km 的最大连通核心面积依次为 92.12、587.88、1,234.08 km²。河网在距河线 2 km 内覆盖沉积地貌面积约 47.0%、52.6%、52.9%，这不是完整水动力覆盖。中心线为增强显示；解析宽度保存在断面，区域格距不能高精度解析所有河宽。灰色负高程是未分类水域，不能认作海洋。地形色彩不是卫星观测或植被分类。

三例使用世界种子 20261020 和各自用途种子；源 TD、坐标、参数与 SHA-256 由本目录各案例产品清单、绘图清单和 [总清单](manifest.json) 绑定。原始基底与高地保留，有限沉积初态和河道挖方分账。45/114/255 km 案例的声明最大海床容纳深度分别为 250/1000/1000 m，属于显著的游戏情景盆地填积假设，不是已观测浅海架。所用流域、流量及物源均为声明情景，地质初态不对应指定日历时长。

地理潮汐证据目前覆盖部分案例且待主端审查：[45 km 的 25 小时事件](../../.scratch/delta-scale-suite-20261102/tidal-basin-v1/tidal-example.png)绑定较早的 `suite-40-basin-v2`，与这里发布的 v7 不是同一产品；[114 km 的 25 小时事件](../../.scratch/delta-scale-suite-20261102/tidal-120-early-v2/tidal-example.png)绑定 `suite-120-early-v1`，早期与最终源高程和掩码已逐格相等，但事件产品身份仍独立。两例均有最终时刻连通诊断，时间步敏感性和局部水深等限制见[潮汐审查](../../.scratch/delta-scale-suite-20261102/tidal-review.md)。255 km 地理事件仍在高水头校准，尚无可接受结论。图片不展示区域潮汐或长期自然演化。

## 主端最终结论
初版地貌与初始河网交付通过，动态水面未全部通过。上文“大型仍在校准”已更新：大型25小时试算完成，终态12河口均与入口连通，但局部岸顶超高5.22m且时间步敏感，保留为待修复结果。中型早期与最终product.npz哈希相同，事件仍保留原始清单身份。[主端验收](../../.scratch/delta-scale-suite-20261102/main-review.md)明确了接受范围；三例均非已完成的长期自然演化。
