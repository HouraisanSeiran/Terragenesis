# 先有界宏观协调，再生成详细河网

Status: accepted

用户在Q1–Q17设计讨论后确认：无限世界以有界宏观规划单元组织山系、海岸和盆地，先冻结完整水文域、共享分水岭和合法终点，再按需生成详细TD派生地形与河床。接受有预算的宏观地形协调以及有界失败，以换取可证明的有限依赖；不在任意原TD上无限追踪、递归合并水系，也不把所有单元限制成独立海岛。原始TD保持不可变，局部4m开挖与宏观塑形及最终总变化分别记录。

首版交付相邻海岸/内流双域的全域粗规划、关键位置精细几何和固定地形的12月周期水账；Minecraft接入、侵蚀反馈和新增暗河后置。加载档位改变资源调度而不改变成果。具体数值参数在小范围标定后冻结，验收不能借参数变化消除失败。完整设计见[水文规划域首版](../hydrological-planning-domain-design.md)。
