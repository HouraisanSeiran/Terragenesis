# 四口三角洲形态验收

本次重新使用现有沉积、分级河网、河宽与水力模块，在真实TD派生浅海上形成连陆低平洲体，再运行600秒水沙验证。

- 连陆沉积体28.62km²，开槽后新生干地约26.37km²；沿岸约8.8km，向海外伸约4km。
- 三个不同位置分叉，包含子支流再分叉，四个独立入海口均实际通水。
- 正常流量1500m³/s，末四口约390/386/393/331m³/s，全部断面未漫岸，库存与保存重算通过。

这是**显式地质构造初态＋短事件验收**。5等效地质年与700数值扫掠形成主体；600秒事件检验可运行性，不代表600秒长出整个三角洲。当前是简化三角洲形态，岸缘仍偏圆，复杂潮沟、洲岛与长期自发演化尚未完成。
