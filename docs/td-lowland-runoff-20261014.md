# TD 大图低地径流承接与河道分离

2026-10-14 首版实际运行完成。使用第三版原生规划的同一幅38.4×38.4km、1280²、30m间距、seed3 Terrain Diffusion 地形；未重新推理模型、改写TD或修改接收图。两名GPT-6.1 Sol medium子代理分别编写算法和验收入口，主协调审查、运行及图审。

## 实现行为与参数

完整汇水图与可见河道分开。每格降雨按显式0.5产流系数生成径流；另一半单列为未进入本径流模型的降雨分量，不冒充已求解土壤、地下水或蒸散。低地降雨不会因不画河道而消失。

低地按局部起伏和坡度识别，不按绝对海拔：半径300m窗口起伏≤20m、局部坡度≤0.025。萌生条件同时检查汇水面积与12个月气候下的集中流量：默认高起伏区域1km²、低地4km²，月平均流量门槛0.015m³/s；满足至少8个月形成持续水流河道候选、至少2个月形成季节性候选。门槛是首版可调工程参数，尚未现实校准。上游已形成的河道向下游闭合，不因进入低地或局部流量不足而截断几何路径。

承接对象沿保存的地形接收图寻找，取第一个实际可达对象，包括本格。主支流、湿地、浅湖、季节性沟槽、洪泛区没有类型优先级；同一位置允许河道与蓄水类别共存。未遇到对象的格子保留无对象标记及最终外围/内部未解去向，不虚构接收河流。

- 洪泛区候选：低地沿接收图距气候支持的初步河道≤300m、相对该河道工作面高差≤1m。不是所有低地都算洪泛区。
- 季节性沟槽候选：有集中季节性径流支持的初步低地河路，不把所有低地输水路径画成沟槽。
- 湿地、浅湖候选：依据已有浅洼工作面抬高范围分类。湿地门槛0.03m，浅湖门槛0.5m，上限4m；这些工作面不是已经开挖的河床或验证完成的湖面。
- 普通低地：保留漫流输送路径，水量继续沿地形进入下游承接对象。

承接区使用有限容量逐格水库：洪泛区0.04m、沟槽0.02m、湿地0.12m等效蓄水深度，浅湖使用候选抬高深度。每月最多蒸发0.015m、释放剩余蓄水的35%，超容量部分沿原图下传。0.12m湿地容量是等效蓄水参数，不是已验证水位。窗口外围不设置库容，内外终点未解出流分别记账。月内下传采用集总近似，并非洪水传播或回水求解。

12个月合成噪波气候按实际365天月长使用，从空库开始重复3年，取第3年判断候选河道。初步河道用于建立蓄水走廊，蓄水计算后的流量用于最终选择。没有迭代拟合分类与走廊固定点，也没有宣称年际稳定或常年河认证。

## 实际验收

先运行新增算法与验收工具的11项关键测试，全部通过，3.786秒。覆盖低地少画河仍保留水、低地零合格湿月仍保留上游干流、承接类型无优先级、禁止跳接/逆坡、蓄水溢流守恒、气候影响及确定性；冷读测试包含修改接收对象、伪造总量仍平衡账本的拒绝案例。

随后实际执行 `tools/review_td_lowland_runoff.py`，只生成一轮大图，31项保存后检查全部通过：原TD/接收图等数组完全一致、来源身份、地形路径上首个对象、独立月水库重算、每格第3年收支、河道萌生及下游闭合。生成、保存和冷读阶段44.142秒；此计时不包含后续绘图，未测量峰值内存。限制2核心、BelowNormal、数值线程1。
