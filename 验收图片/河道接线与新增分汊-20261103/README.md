# 河道接线与一次新增分汊

两个同源工程案例已经分别通过主端数据与实际床面检查。它们采用不同流量、时间和计算格距；图集展示各自证据，不表示两例同步联合演化。

- **01 上游河道接至河口**：真实TD30m地形上，约18.2km末端河段按地形细化。河槽投影15m、海岸600m；插值不增加TD细节。Q150m³/s、固体0.08m³/s为情景；水面使用全河段平均摩阻坡降下的准稳态近似，固定海位0m。两个25h时段完成有限输入和在途库存续存交付。底图颜色为地形配色，不代表植被。X东、Z南向下。
- **02 纵剖面**：实际派生河床和近似水面，河口保持指定海位。未求解沿程回水和逐段能量方程。
- **03 新增分汊局部床面**：Q3000m³/s、固体1.6m³/s的另一假定情景。旧控制段淤浅后，有限切穿三处沉积格，形成第四个出口。数字为实际格高程，线只表示计算路径；单格600m不是真实河宽。此诊断图用网格坐标，Z向上。一次25h潮浪后四路通海。

原TD、共同地质基底和历史输入保留。河槽开挖的170.77万m³原位体积去向未知，独立记录；新增分汊切出的43.59万m³固体进入共同移动库存，两者不混账。

保存状态和实现快照见“数据与实现”，独立检查结果和来源见manifest。更长期多分汊尚在验收，百公里大型三角洲等待条件具备再实施。
