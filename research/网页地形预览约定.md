# Terragenesis 本地地形预览

目标：在进入 Minecraft 前查看已生成的数据，并检查分区处理前后的差异。先完成治理和派生流水线验证，再接入网页。实现代码继续由 GPT-6 Sol 承担。

## 数据边界

- 网页读取实际 Java 处理器的输出，不复制一套地形算法。原始高度、派生高度、四类连续权重、世界原点、采样间距和算法身份必须一同导出。
- 首版可读取保存的真实模型样本及其派生 NPZ；这是样本预览，不宣称可以查看整个无限世界。后续增加游戏区域成品读取。
- VDM 本阶段仅包含垂直位移：`dx=dz=0, dy=derivedHeight-rawHeight`。地形网格不能据此显示不存在的洞穴或悬挑。
- 所有 XYZ 使用方块单位，海面参考为 Y62，默认不夸张纵向比例。若用户调节显示比例，应明确标出，仅影响显示。
- 预览抽稀只影响显示；指标和坐标查询注明使用的数据分辨率。没有数据的范围保持空缺。

## 首版交互

1. 选择低地、高原和高山真实样本。
2. 三维旋转、缩放、复位；原始与处理后高度切换。
3. 高程、主导地貌、四类权重以及高度改变量图层。
4. 查看世界坐标与高度；显示种子、算法身份和采样间距。
5. 保留二维视图，便于观察分区和边界。

界面使用中文。启动只绑定本机地址，不上传样本、不启动模型推理、不改写游戏存档。不依赖运行时下载 CDN 脚本。静态文件、数据准备、服务入口和渲染职责分别组织。

## 验证

导出前校验有限数值、数组尺寸、权重范围与归一化、原点及单位；证明显示高度来自保存的结果。验证本机接口及页面脚本，记录三维渲染的浏览器实测范围。网页渲染不是 Minecraft 截图，不代替游戏内观感验收。
