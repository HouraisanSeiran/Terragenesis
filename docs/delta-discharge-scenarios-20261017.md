日期：2026-10-17。用户允许增大河流流量，以检查河口陆侧冲积平原的沉积响应。本轮已完成原来水2倍、5倍、10倍的一年演算，并与只读复用的1倍基准比较。

在当前固定地形和有限物源下，增流量能够扩大部分陆侧薄层沉积，但不会增加已经耗尽的全年供沙。5倍情景的陆侧床升至少1mm面积最大，为0.2204km²，约为基准的5.86倍；各增流量情景在原构造干地上的最终沉积均不足1cm。10倍情景约92.9%的泥沙最终外排，未形成更厚的冲积平原。上述结果只代表本次模型和材料情景。

## 计算方式

运行器新增`--discharge-scale`，要求倍率为正有限数，缺省为1。倍率作用于上游39个保留控制体的每一天、每个节点，保持原季节曲线。重新根据初始坡度和Manning公式计算水深，生成带有新水力身份的合法来源，再进行逐日床面、水力、侵蚀输沙反馈，精确汇总至原来的12个月界。三角洲消费实际出口来水和来沙，重新求解分流、水位、沉积与再搬运。

地形、河道宽度和拓扑、岩底、硬度、初始松散层及移动库存、外部泥沙边界均与基准相同。构造过渡段继续只传递上游输出，不交换已被整地移除的旧材料。未将来沙直接乘以流量倍率，未增加材料库存，未改动三角洲数值核心。情景参数、基准和实际逐日出口流量均保存，冷重放从原始来源及记录倍率重新构建。

各档初始可侵蚀岩石约30,122.988711m³固体，松散泥沙约978.997133m³固体；39个控制体的有限岩床全部耗尽，剩余岩石仅为约10⁻¹⁰m³的浮点尾量，松散与移动库存耗尽。基准已经达到此物源上限，因此提高水量主要改变侵蚀输出时序、含沙比例和河口输移。年均泥沙固体/水体积比从1倍的1.5770×10⁻⁵降至10倍的1.5770×10⁻⁶。不能重复使用这一年输入来延长地形增长，除非另行明确并计算新增物源。

## 陆侧响应

本表的陆侧采用相同的“构造完成后、演化前床面高于海平面”掩膜。床升面积指已有陆地上的沉积厚度，并非新造陆面积。

| 来水倍率 | 陆侧净留存m³固体 | 床升至少1mm面积km² | 床升至少1cm面积km² | 实际新增干地km² |
| --- | ---: | ---: | ---: | ---: |
| 1 | 562.533 | 0.0376 | 0.0004 | 0 |
| 2 | 602.662 | 0.1196 | 0 | 0 |
| 5 | 1,030.213 | 0.2204 | 0 | 0 |
| 10 | 1,210.107 | 0.0876 | 0 | 0 |

5倍情景在所比较的四档中具有最大的陆侧至少1mm淤积范围；10倍的陆侧总留存更多，但摊铺更薄，至少1mm面积反而下降。没有把5倍称作普适最优流量。

“构造前原陆地”掩膜包含后来挖成河槽的区域，其净留存分别为26,336.585、18,046.063、8,271.267、505.307m³，不能与本表陆侧平原的干地参照混用。各档海平面零基准穿越面积分别为15,600、12,400、4,000、1,200m²，但最终仍淹水，实际新增干地均为零。

本轮没有改变现有平原范围、保护区或河道拓扑。已有低地上的毫米级沉积在16km总图里不显著，不能根据保持相近的大轮廓将其描述为新长成了大面积厚冲积平原。

## 验收

主协调审查了来源缩放、库存保持、参数保存、重放与非空输出保护。新增10项参数测试加原15项集成测试，独立运行共25项通过，5.83秒；本轮未重跑之前的101项全回归。

2/5/10倍每档年度演算及随后冷启动重放顺序执行，单次数值进程采用两核、BelowNormal及数值线程1。各档`cold-audit.json`确认重新裁切来源、逐日反馈、月界输入、完整三角洲数值数组与水力状态精确重现；清水对照床面不变。

主协调独立读取保存数组，核对全部初始材料数组逐项相同、所有节点逐日Q精确乘以指定倍率、床面按库存/孔隙率精确重建、毛沉积减再搬运等于净库存、保护区床面不变、水深对应实际水面减床面。三档上游来河、扇顶和三个海侧端点均连通。联合固体残差绝对值最高1.46×10⁻¹¹m³，水量边界残差绝对值最高7.63×10⁻⁶m³。

开始和结束的独立SHA比较确认原始4份输入，以及03基准的`result.npz`、`summary.json`共6份文件未变。主协调实际查看了数量面积对比图、5倍16km场景、5倍沉积图与2倍扇顶细节。

## 后续地形演算

用户已提出：算法成熟后基于Terrain Diffusion地形演算。后续应使用生成地形上的河网、坡度、汇水来流以及明确的岩性和可侵蚀库存，检验不同河口与陆侧低地；这一步尚未实施。

当前结果显示，仅增加固定断面河流的流量不能解决大规模造陆。要进一步得到广阔冲积平原，需明确更完整的坡面、河岸、支流物源，并评估低地连通和漫滩输沙的空间计算；这些应单独建情景与预算。本轮没有凭空补沙或修改地形来使结果更明显。

模型仍为准稳态固定宽度河道树与连通淹水近似，不求解洪泛区完整二维流量分配、水体体积或支汊自行生成。高流量结果用于当前模型的敏感性比较，未作真实大河标定，未发布至默认世界或游戏。
