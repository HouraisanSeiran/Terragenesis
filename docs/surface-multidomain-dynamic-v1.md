# Surface multidomain dynamic forest v1

`prepare_surface_multidomain_dynamic(evaluation, *, conductance_m2_s, local_q_m3_s, tailwater_m, dt_s, max_depth_m, resources, limits, cancel)` accepts the entire saved, accepted `surface_domain_prepare` evaluation. It binds every declared prepared domain through the existing single-domain adapter, then calls `dynamic_surface_hydraulics.evaluate` once on a global graph. There is no domain selector. Node identity is `(domain_id, flat_node_id)` in ascending domain and flat-id order. Edges receive each domain's node offset; no cross-domain edge is created. Two separately draining domains stay two components.

Caller arrays use the saved global order: positive constant linear conductance `K[E]` in m2/s, signed **local** `Q[T,N]` in m3/s, and tailwater `[T+1, all outlets]` in metres. Local Q is never inferred from source accumulated Q. `dt_s` is physical seconds. The existing explicit diffusive stability gate is `dt_s * sum(K incident to node) / A0 <= 1` for internal nodes; this is not a shallow-water CFL condition. Boundary nodes carry prescribed stage and zero storage. Fixed `A0` is the unique actual wet-cell area assigned by the old adapter, including boundary support area; boundary area contributes no stored volume.

The saved record retains the original evaluation, every source binding, global mapping, immutable hydraulic inputs, committed prefix, failed-step diagnostic when applicable, and six-column per-domain step ledgers. The ledger columns are `storage_before_m3`, `local_volume_m3`, `boundary_into_storage_m3`, `storage_after_m3`, `storage_change_m3`, and `residual_m3`. Boundary inward volume is counted once per component and internal edge fluxes cancel. Static validation checks source identities and accepted status, each binding's saved topology and wet ownership, global offsets/edges/area/bed/stage, dynamic equations/time/prefix, each domain ledger and its sum against the global ledger. Query accepts only a saved committed state; load and query never bind or advance.

The bundle is an atomic no-overwrite ZIP with a strict manifest and NPY v1 arrays. The loader checks unique members, resource bounds, array references, actual headers, shape, dtype, byte size and hashes before accepting the record. It rejects object arrays and pickle. Resource limits cover domains, wet cells, assignment work, nodes, edges, steps and retained/working bytes. Cancellation during binding raises `InterruptedError` without a partial product; during time advancement it preserves the committed prefix. A failed step also preserves only the committed prefix.

This is a finite engineering storage/conductance model with caller-supplied constant `A0`, `K`, local Q and tailwater. It does not derive section `V(h)`, solve momentum or tides, certify natural outlets, or establish natural terrain/water continuity. The fixed verifier uses the unchanged old prepared two-domain evaluation and records source, bundle and four implementation-file hashes plus focused test log in a UTC verification directory.
