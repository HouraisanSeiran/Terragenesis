# 遥感式验收图片规范

生效日期：2026-10-31。用户要求：一、二阶段工程成果尽量以遥感图形式检验，今后交付用户的验收图片沿用此形式。

## 默认交付

用户于 2026-10-31 补充：主验收须采用世界尺度的连续地图，参考 `relief.png`、`topo.png`、`topo2.png` 的地形、海岸和水系表达；尽量在同一世界上使用一、二阶段的大部分算法。局部专题图作为补充，不能以局部图集完成世界尺度验收。最新批准的审查范围为独立单大陆的 **500 × 500 km、全域 90 m、关键区域 30 m**；先交付同一世界中的 **64 × 64 km** 样图，用户审阅后再扩展。12,288 km 是历史方案。世界概览采样间距、区域计算间距和原生 TD 间距分别记录；审查窗口不作为无限世界生成代码的终止边界。

优先复用既有 `terrain_map_style.py`、`render_terrain_map.py` 的地图要素和已有计算模块。粗尺度计算必须使用支持该格距的物理接口；不能只放大已有窗口、反复铺贴 TD 样片，或仅提高图片像素来代替世界范围计算。已有五通道地理条件场用于规划，不能单独作为已经生成的 TD 地形或已经运行的环境结果。世界主图的具体缺口与历史复用入口见[当前任务](../.scratch/world-scale-acceptance-20261031/spec.md)。

主成果图默认使用从上方观察的遥感式合成影像：真实保存地形的阴影与地表配色，叠加保存水体、河槽及已经计算出的地表覆盖。每个专题先给可直接检查空间形态的主图，再按需要附定量专题图、剖面或收支表。诊断面板是证据补充，不能代替主成果图。

**所有新验收图片必须以 Terrain Diffusion 生成地形为验证基础。** 每张图均须能追溯到具体保存 TD 页、文件摘要和地形产品身份；降水、材料和生态等专题也必须使用该地形同址输入。独立合成平床、纯机制网格或现实参考 DEM 可作开发对照，不能替代 TD 地形上的算法验收。三角洲等允许修改派生高程的过程，要同时保留 TD 原始来源和构造/演算的改写说明。

**2026-11-03 独立后端适用范围更新：** 用户已明确启动不依赖TD的多形态山体生成。其图集绑定实际保存的独立程序化来源、种子、算法版本和数组摘要，明确标记非TD；无需额外生成TD来取得本后端形态与性能证据。保留同源俯视主图，并补无材质多视角几何与细节关闭对照。既有TD链的验收仍按上段执行，新来源不冒称已与TD或水文耦合。总体评价见[根目录标准](../无限世界地形生成评价标准.md)。

优先在同一张图中检验多个算法的联合结果，例如 TD 地形＋河网＋湖泊＋派生床面，或同址地形＋降水/水分＋土壤＋已计算覆盖。每图记录参与的算法；联合叠加必须共用坐标、地形身份和对应时间。并排专题须明确是同一状态的不同量还是前后/情景对照；多个独立案例不能拼成已经耦合的结果。

这里的“遥感式”是模型结果的可视化，不是卫星观测，也不是经过传感器或光谱标定的真彩色影像。图注使用“遥感式合成影像”；仅使用高程和坡度配色时写“地形配色”，不能声称已有植被、积雪或地表材质分类。禁止用生成式图片补造验收地貌。

## 表达方式

2026-11-01 更新：500 km 扩域已由用户暂停，先处理 64 km 样图暴露的问题。后续宏观基底按板块构造驱动大陆的方向设计；规划图须标为宏观计算结果，不替代 TD 地形验收。

季节积雪采用保留地形阴影的半透明地理遮罩，与永久积雪分开。当前制图阈值为月末 SWE ≥ 10 mm，冷白/淡青色，不透明度 35%；图和清单记录月份、阈值及实际面积。若仅有一个模拟年的十二个月末状态，其交集只能标注“全年残留积雪（本模拟年）”，不能认定永久积雪或冰川。永久积雪须另有多年持续性证据，冰川须有实际冰厚/流动等模型结果；没有相应数据时不得按高程涂白补造。季节比较使用同一地形与地表背景，仅改变积雪遮罩时须明示，不能解读成整套生态/水文月度快照。

| 成果 | 主图或专题图 | 验收时检查 |
| --- | --- | --- |
| 宏观海陆、千岛、千湖基底 | 海陆与高程俯视图，标注宏观采样 | 海岸连通、陆块形态；千湖候选基底不画成已经形成的湖泊 |
| TD 地形与高程调整 | 同源原始/派生地形遥感式图，另附高程差 | 接缝、条带、人工边缘、实际改写范围 |
| 河网、河湖、汇流 | 地形底图叠加保存河网；有床面/水位时绘制实际湿区 | 主干连续、汇流、出口、湖岸；区分拓扑线与实际湿河槽 |
| 降水、温度、风和雨影 | 地形底图上的空间专题图，明确单位与色标 | 迎风/背风、地形相关性、空间缺失及量级 |
| 季节与气候情景 | 同坐标、同色阶并排图及差值专题图 | 月份/时段与驱动；季节对比不称长期气候变化 |
| 土壤、地下水、冻土、盐分、辐射 | 地形定位图及定量专题图 | 厚度、水头、库存或通量的真实单位；地下量不伪装成可见地表 |
| 雪冰、植被、扰动恢复 | 已计算覆盖或库存的俯视图与前后对照 | 初始条件、时间、实际覆盖变化；声明的初态与计算的变化分开 |
| 侵蚀、风沙、火山、海岸沉积 | 原始/派生表面图，另附床变或物质专题图 | 几何变化的量级与物源；不可见微变不靠夸张渲染冒充地貌 |
| 三角洲、潮沟、沙洲 | 床面及实际水位的遥感式图，同源低/高潮对照 | 分汊方向、通海、沙洲、潮沟与岸线，构造初始分汊明确标注 |
| 栖息地、迁移及其他不可直接见的量 | 同源地形上的专题叠加 | 适宜度与真实占据/迁移分开，不能用画出的动物证明模拟完成 |

## 每次交付的最少信息

- 图片：范围、方向/坐标约定、比例尺、图例；专题量显示单位和色标，标明时刻或累计时间。
- 来源：世界种子、世界/产品身份、输入路径及文件摘要、原始格距或不规则网格说明、输出采样尺度；这些信息可放同目录报告，图中保留能定位它的标题或编号。
- TD 基础及联合关系：逐图写明 `terrain_basis`、TD 来源绑定链、参与的 `algorithms`；只有元数据写了 TD 字样而缺少实际来源，不能判为 TD 地形验收。
- 画法：地形配色、光照、垂直夸张和河流显示阈值明确记录。上采样不能被称作更高物理精度，线宽增强不能被称作实际河宽。
- 范围：有效、未知、未覆盖和保护区的语义保留。未知不得涂成海洋、干地或零降水；不同世界/案例不拼接成统一成果。
- 对照：前后/月际图片锁定坐标范围、色阶及光照；差值保留单位，零变化如实显示。气候变暖等外加情景注明驱动，只有实际多年演算才报告长期变化。
- 核查：检查图像非空、文字及色标可读、水体与源字段对应；保存必要的定量检查与失败项。形态由用户验收，图片不替代守恒、连通、冷读或消费者验证。

每个图集的 `manifest.json` 还要给专题写 `coverage_status`：`complete_in_window` 表示声明窗口内的字段已完整呈现；`partial` 表示只覆盖部分空间、时间或状态；`mechanism_only` 表示有限机制/账本证据，可含局部栅格诊断，但不足以确认目标地貌或生态表现；`not_available` 表示输入或消费者尚未提供。图集总的 `pass` 只代表图片和来源检查通过，不把这些状态折算成阶段完成率。

细流可按既有流量/宽度阈值隐藏，只影响显示，原计算贡献仍沿原汇流关系进入大河。禁止为图片另造排水路径；现行河网图读取替换 D8 后的保存产品，历史 D8 图只作明确标注的历史对照。

## 目录与复用

每次生成使用新的 `.scratch/<专题>/` 输出目录，保留图片、来源和验收记录，不覆盖历史证据。用户交付入口放到根目录 `验收图片/` 下可辨识的专题目录；原验收报告与副本之间保留可追溯链接。

已有合格图可以复用，但需记录原图、原输入和原验收的范围。缺少对应空间数据的模块在覆盖表中列为“仅机制证据”或“缺少空间输出”，不能补一张示意图后宣布通过。仅重新渲染已保存结果时，应写“只读重绘”，不声称本轮重跑了整个数值过程。

历史图片保持原样，本规范约束此后新交付，不要求重新美化全部旧档案。既有渲染入口包括 `tools/render_remote_sensing.py`、`tools/render_terrain_map.py`、`tools/render_environment_world.py`；新专题优先复用其地形着色、真实湿区和尺度规则。
