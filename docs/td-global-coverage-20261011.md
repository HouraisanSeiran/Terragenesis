# TD 全域覆盖与前端同步

本轮完成既有50条拒绝边的交付范围划分，以及真实TD底图上的全域覆盖审查。原673条河段中623条已有局部几何验收，50条保留未解决；未新增接受边，也未评估新的重路由。issue 13仍开放。

`verification/td-valley-global-tiled/td1024-20261011-01/scope-exclusion.json` 绑定原拒绝诊断、失败报告的SHA、来源和计划身份。27条既有路径的中心线支撑跨owner；50条在原河岸半径0.1倍的诊断下仍跨owner。0.1是无量纲系数，不是0.1米，也不能据此证明任意合法重路由不存在。历史记录中相关单位和不可能性表述以本说明为准。

前端入口为 `http://127.0.0.1:8765/?workspace=global`。只读API `/api/river-results/global` 校验网络计划和证据关系，从组件实际接受边集合构造绿色图层，从排除清单构造红色图层；两者合计覆盖原673条声明边。底图按源坐标显示原TD采样，图层表示覆盖状态，不是完整细床水面。支持逐条排除边选择、图层开关、缩放平移和含来源、排除、覆盖、材料账的导出。

验证：scope-exclusion及前端绑定测试通过，真实桌面/移动端检查覆盖图像、图层像素差、逐边选择、导出和返回默认成果页。证据在 `verification/td-river-release/global-coverage-20261011-02/`。原M8六案例桌面/移动端回归证据在 `verification/td-river-release/m8-global-sync-20261011-01/`。

全域几何、湖盆/回水、水力床变反馈及M7收敛等未完成门禁保持开放，`publishable=false`。
