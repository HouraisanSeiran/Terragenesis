# 无限世界地理概念：收益排序与验收参考

状态：讨论参考，非已批准实现清单、非已有功能验收结论。来源：2026-10-20 用户讨论；后续逐项立任务并确定尺度、成本与测试后才能称“完成”。

## 使用原则

本项目按需生成无限世界。对每个坐标，以可重复的大尺度背景（可以用多尺度噪波，也可用确定性规则）提供基础，再由周围海陆、地形、材料和水等**当地条件**修正。噪波提供变化，不替代因果规则；不能把地球有限球面的经纬度、日照或全球环流直接声称为无限平面的物理事实。每项实现需说明坐标、单位、影响范围、查询依赖上限、边界衔接与简化假设。现有 v2 周期带是合成气候背景，**不是真实纬度/日照**。

“收益”指对当前地形、水与景观可信度的预计贡献，并非实测性能排名。A=优先建立/补强，B=基础成形后再做，C=按景观目标选做；同一档不规定严格开发顺序。表中“验收参考”是将来做该功能时应验证的现象，不代表现已通过。

| 概念 | 收益 | 无限世界中建议怎样用 | 将来验收参考 |
|---|---|---|---|
| 海陆与海岸 | A | 大尺度连续背景，局部确定海岸；不预设一颗有限地球 | 任意坐标可判海陆；跨窗海岸连续，河流入海口有效 |
| 山系、盆地、高原 | A | 大尺度地形约束叠加局部起伏，不把局部噪波直接当山系 | 相邻窗口接续；山脊、低地和水流方向彼此相容 |
| 岩石、岩层、断层 | A | 材料属性和层序须可查询；断层若存在须影响岩层/地形，不能只画线 | 同一坐标材料身份稳定；露头、断崖与岩层一致；明示合成而非实测 |
| 板块运动/构造 | C | 可用有限影响的构造背景安排山系与断裂；不必模拟完整地球板块史 | 使用时，山系/断裂/材料分布与构造规则相容；未做不得声称板块模拟 |
| 大尺度冷暖背景（非真实纬度） | A | 用确定性缓变场、周期场或噪波；明确虚构世界坐标语义 | 同点重算一致；跨窗连续；背景不被宣称为真实地球纬度 |
| 季节与日照 | B | 先定义虚构年的季节规则；无球面/自转设定时不称真实天文日照 | 月度冷暖和雨雪变化自洽；若声称真实日照，须先有世界几何与天文设定 |
| 海拔降温 | A | 基础温度受当地高度修正 | 同一背景下高地通常更冷；雪线与温度条件一致 |
| 盛行风 | A | 缓变风向/强度背景；局部地形可修正 | 迎风、背风判定稳定，跨窗不突变 |
| 迎风增雨与雨影 | A | 风场与地形共同决定降水增减，不只给雨量叠噪波 | 对照相同背景下山两侧雨量；与产流使用的雨场不漂移 |
| 气压带 | B | 不照搬地球固定纬线；可作缓变干湿/风带背景 | 在定义的尺度上影响风雨，过渡连续，不把背景标签当真实气压观测 |
| 季风 | C | 有海陆与季节风向条件时引入 | 雨季/旱季与风向和水量响应相符 |
| 洋流 | C | 有连续海洋、海岸和风场后再建沿海水温影响；非随机冷暖流标签 | 流路不穿陆、邻近海岸的气候影响连续；无海洋依据则不启用 |
| 蒸发与土壤蓄水 | A | 区分降雨、实际可用水和下渗储水 | 水量有去向；干湿景观不只看年降水 |
| 分水岭、流域、河网 | A | 按需查询的有限依赖规则，不能以窗口边界定义河流 | 同世界点跨窗/乱序一致；流路和出口连续；拒绝条件明确 |
| 地下水与泉 | B | 依赖岩石透水性、水源与储量近似 | 泉源有补给；地下水和地表水交换不凭空增水 |
| 湖泊、湿地 | B | 结合地形蓄水、淹没时间与排水，不靠“湿地”标签倒推 | 水位/出流/湿地条件与邻接河流相容 |
| 冰川、多年积雪 | C | 仅在长期低温与降雪条件成立处生成 | 冰雪范围与气候相容，融水有去向 |
| 海岸侵蚀、潮汐、河口 | B | 先确保河海衔接，潮汐等再作为海岸过程 | 河口接海，泥沙或挖填可追踪；未模拟潮汐不声称潮汐塑形 |
| 风化、侵蚀、沉积 | A | 材料经风化、搬运、堆积改变地形，不让物质无故消失 | 高度变化与物质去向一致；边界通量明确 |
| 土壤与地表覆盖 | A | 由材料、气候、水和坡度决定土、砂、裸岩、雪等 | 可在同坐标查询厚度/覆盖；与植被和湿地条件相容 |
| 生物群系与植被 | A | 群系是环境概括，具体植物须受温度、水、土和扰动约束；可指定目标再反推条件 | 不只验证标签/资源在场；同坐标实测环境与实际植被相容，说明游戏侧是否已接线 |
| 动物与生态关系 | C | 建立在水、植被和栖息地之上 | 栖息地条件可解释分布；不算基础地形生成的必选项 |
| 人类聚落与土地利用 | C | 单独的后续层；纯自然世界可不做 | 若启用，聚落/道路与地形、水及资源可达性相容 |

## 建议的先行组合与边界

优先让已有地形、水与气候相互吻合：海陆/山系背景 → 缓变冷暖与风 → 地形修正降水 → 水系 → 材料/风化与沉积 → 土壤/群系/植被。箭头表示**安排工作的依赖建议**，不是自然界只能单向作用：水会改地形，植被也影响土壤。是否将板块、洋流、真实日照作为目标，须另行确定世界几何、预期景观和计算成本；不要自动加入当前河网任务。

验收时区分三件事：①代码/规则可计算；②指定种子与同一坐标的实际联合观测；③默认使用方已经接线。单项出现、不同地点各自出现或分类直积可达，不等于同一片真实景观已具备全部组合。记录可重跑种子、范围、间距与已知退化/拒绝，不用没有出处的“自然真实”作为通过条件。
