# 2024 多层高度图论文与独立侵蚀原型

已直接阅读 Nilles、Günther、Wagner、Müller，*3D Real-Time Hydraulic Erosion Simulation using Multi-Layered Heightmaps*，VMV 2024，DOI `10.2312/vmv.20241211` 的 8 页 PDF；本地副本为 `nilles-2024.pdf`。

论文在多层高度图的各列之间用 virtual pipes 输水，区分基岩、砂和含沙水。其水平侵蚀检查相邻列中的水与目标基岩高度重叠，结合重叠面积、倾角、邻列流速与流向计算 damage；damage 积累达到阈值后分裂基岩列。随后迭代传播支撑度，并处理失稳列。本文原型没有复刻这些水流、damage、列分裂或支撑算法，也没有采用论文 GPU 性能数据。

`com.remotemountains.erosion3d` 是与河网独立的纯 Java 实验接口：`SweptPath` 在三维折线上寻找最近线段，给出沿线切向、稳定局部横向/上向基及有限作用权重。路径权重只限定作用域，不计算水力。`SurfaceSample` 明确提供已湿润接触标记、水深、表面法线、面积、外部水力求解器给出的剪应力及岩石参数；未接触水的埋藏面不会退缩。`Erosion3d` 用经验阈值式和步长上限产生沿内法线的 VDM 位移。`area × retreat` 只是局部一阶移除体积近似，不证明整个变形网格的精确体积守恒。

`SedimentLedger` 以固体等效方块体积记录移除基岩、产沙、移动库存、已沉积库存和边界输出。只有调用者明确 `deposit` 后，才能按孔隙率把沉积物转为整方块；小数余量保留。此处没有流水求解、输沙能力、河床演化、洞穴重拓扑、落石或 Minecraft 接入。要产生论文式悬挑/洞穴，需另行实现多层列分裂及支撑检查，并以真实边界条件验证水沙收支。当前独立验证覆盖法向与路径方向分离、域外/埋藏面零侵蚀、水深和剪应力阈值、步长封顶，以及分数沉积与孔隙率记账。
