# 长垣：以扩散模型为基础的地形算法调研

调研日期：2026-09-27。目标：Minecraft Java 26.3 / Fabric，按地貌区域生成平原孤山、东非裂谷式地貌、桂林喀斯特和张家界柱群；区域约 1,500～4,000 格，气候允许自由组合。

## 0. 核心纠正与资料范围

**基础高程必须来自真正的扩散模型推理。** 地貌布局、Perlin 噪声、侵蚀、向量场、VDM 和洞穴算法只能提供条件、引导或后处理，不能替代扩散模型，再把结果称为“扩散地形”。

当前 Java 原型不满足这项要求：孤山是椭圆距离幂函数叠加噪声，并非扩散生成。当前 JAR 和预览只保留为原型记录，不能作为正式地形效果交付。

本轮是面向本项目的广覆盖调查，不声称穷尽所有公开算法。信息分为：

- **已读取项目说明／接口源码**：确认项目公开声称的能力，没有据此声称本机已运行或达到作者性能。
- **论文题录／公开实现中的引用**：可以作为进一步阅读入口，不等于已审阅整篇论文。
- **工程推导／拟议组合**：下文为本项目设计的连接方法，尚未经过实验验证。

资料原文、HTTP 状态、时间与 SHA-256 位于 `sources/` 和 `sources.json`；失败链接明确保留状态，不作为已读证据。数学细节见 [数学工具箱](数学工具箱.md)，实际开发路线见 [扩散基础架构](扩散基础架构.md)。

## 1. 本轮最重要的发现

1. [Terrain Diffusion](https://github.com/xandergos/terrain-diffusion) 已有层级地形生成、预训练模型和自定义粗条件输入。应优先作为基础生成器，而不是一开始重训整套系统。
2. 官方说明中 30 m 模型的粗条件尺度约为 **7.7 km**，90 m 模型约为 **23 km**。这决定了控制精度：不能期待在极粗条件图里精确放置一座几十格宽的石柱。换算成多少 Minecraft 格取决于米／格映射；例如 15 m／格时，7.7 km 约对应 513 格。不能直接把公里与格数比较后断言区域一定无法控制。
3. **插值提高像素数量不等于生成新的地貌细节。** 本轮读取 `inference/api.py` 发现 `scale > 1` 路径包含插值上采样。必须区分模型原生分辨率、实际生成细节、Minecraft 每格代表的尺度。
4. 现有条件通道是高程与气候，不是四种地貌类别。要稳定产生指定地貌，需要评估现有条件能力，必要时增加地貌条件分支或用地貌数据微调。
5. 现有文档与源码存在接口差异。例如 API 文档仍有相对 90 m 的描述，而源码描述为模型原生尺度，并通过查询参数切换种子。接入必须锁定版本、核对源码与模型配置，不能直接照抄旧文档。
6. 高度图能表达峰林、台地和沟谷；悬挑和洞穴要由 VDM 网格、SDF 或体素层补足。**VDM 不是三维密度场，RGB 外观也不是有效几何数据。**
7. 导数、曲率、流域与拓扑分析既能控制地形，也能衡量“不自然”：山峰间距过于均匀、山脊连通度过高、平地比例不足，都可以量化。

## 2. 扩散与学习式生成

| 方法／项目 | 核心作用 | 本项目用法 | 成熟度与限制 |
|---|---|---|---|
| [Terrain Diffusion / InfiniteDiffusion](https://github.com/xandergos/terrain-diffusion) | 分层生成高程与气候；无界采样、按坐标访问与种子一致性 | 必选的首个基础模型候选；保留原始模型输出用于审查 | 有公开模型和 Minecraft 实现；不是直接生成三维洞穴，也不是开箱即用的四地貌分类模型 |
| [Terrain Diffusion Minecraft](https://github.com/xandergos/terrain-diffusion-mc) | 模型推理、世界生成及群系映射 | 参考 Java 端推理与缓存；核实目标版本兼容性 | 模组存在，不代表可直接用于我们的 26.3 工程 |
| [DDIM](https://github.com/ermongroup/ddim) | 去噪扩散的采样方法；可采用确定性采样 | 在模型支持时减少步骤，便于复现对比 | 不负责让模型学会喀斯特；确定性仍依赖模型、调度器和数值后端 |
| [EDM](https://github.com/NVlabs/edm) | 噪声参数化、预条件与采样设计 | 理解 Terrain Diffusion 的 EDM 网络与采样设置 | 不能随意与另一模型的噪声日程互换 |
| [DPM-Solver / DPM-Solver++](https://github.com/LuChengTHU/dpm-solver) | 用高阶求解器加速扩散采样 | 后续比较延迟与地貌保真度 | 需匹配模型预测类型、噪声日程与引导方式 |
| [Latent Diffusion](https://github.com/CompVis/latent-diffusion) | 在压缩潜空间生成，再解码 | 降低大范围地形生成的成本 | 自编码器会丢失窄峰、断崖等高频结构，需检查重建能力 |
| [Consistency Models](https://github.com/openai/consistency_models) | 少步生成或蒸馏加速 | 无限世界运行时延迟优化 | 通常需训练／蒸馏；并非把普通扩散步骤直接删到一步 |
| [MultiDiffusion](https://github.com/omerbt/MultiDiffusion) | 融合重叠窗口的去噪过程 | 理解区域约束与拼接；与 InfiniteDiffusion 对照 | 通用图像方法；不能自行保证无限地形随机访问和水文一致性 |
| [ControlNet](https://github.com/lllyasviel/ControlNet) | 为扩散网络增加空间条件分支 | 候选输入：地貌区域、平地、山脊、河道、断裂线 | 已发布的图像 ControlNet 权重不能直接接地形网络；需要结构适配和训练 |
| [Diffusion Posterior Sampling](https://github.com/DPS2022/diffusion-posterior-sampling) | 根据可微观测约束引导采样 | 探索平地比例、低频高程、边界高程等约束 | 本项目的约束需新实现；额外反向传播成本，不保证任意约束都稳定 |
| 区域修补／inpainting | 冻结或约束已知区域，重新生成局部 | 修改标志景观，同时保留外围生成地形 | 需模型及采样器支持；窗口重叠不足会出现坡度接缝 |
| 地貌条件微调／LoRA | 学习特定形态分布 | 让“孤山／峰林／柱群／裂谷”可控 | 属于拟议方案；是否采用 LoRA 需查看具体网络，不假定官方已有适配器 |
| [Adaptive Diffusion Terrain](https://github.com/youwyu/Adaptive-Diffusion-Terrain) | 面向机器人导航、难度条件的高程生成 | 参考“可控地形属性”训练与测试 | 主要面向导航难度，不能据此认为能生成真实大型山系 |
| [Neural Terrain Generation](https://github.com/novaia/ntg) | 生成高程的学习式模型训练管线 | 备选架构与训练数据流程 | 已读简要说明；具体模型版本、效果和权重可用性待进一步核实 |
| [Text2VDM](https://github.com/HengyuMeng/Text2VDM) | 扩散模型通过 SDS 引导平面网格变形，生成 VDM 笔刷 | 离线生成局部岩壁、石层与悬挑资产 | 是优化式生成，不是实时无限地形模型；不能把运行设备当最低显存要求 |
| [TRELLIS](https://github.com/microsoft/TRELLIS) | 结构化三维潜表示与三维资产生成 | 研究局部三维地貌表示／训练数据生成 | 资产级三维生成，不是可直接替换的全球地形生成器；与经典去噪扩散的具体生成形式需分开描述 |

**针对用户审美问题的优先顺序：**先解决扩散模型的训练分布、条件图和尺度问题，再做有限侵蚀。若原始模型已把所有山体连成相似山脊，反复水蚀通常不会自动得到有布局层次的孤山与峰林。

## 3. 程序化信号、区域划分与地形约束

这些方法主要生成扩散条件和少量细节，不担当最终主体山形。

| 方法族 | 用途 | 在扩散流程中的位置 | 风险 |
|---|---|---|---|
| Perlin / Simplex / OpenSimplex | 连续可复现的空间变化 | 气候、岩性、粗高程条件及细节扰动 | 噪声的分形外观不是地质成因 |
| fBm、多重分形、ridged noise | 控制尺度分布、粗糙程度与脊状信号 | 粗条件和轻量局部残差 | 全地图同一套频谱会造成审美重复 |
| Worley / Voronoi | 区域归属、最近岩体／种子距离 | 不规则地貌区域及柱群密度控制图 | 直接当石柱高度会出现规则“插柱子”效果 |
| Domain Warping | 用向量场扭曲采样位置 | 扭曲区域边界、断裂线、条件图 | 过强形变导致折叠、河流方向失真；检查 Jacobian |
| Curl noise | 构造局部无散度扰动 | 风场扰动、局部形变、洞穴路径方向 | 不可直接当重力水流；无散度不等于自然排水 |
| Poisson disk / blue noise | 具有最小间距的非网格点分布 | 地标候选点、训练采样窗口 | 固定半径仍可能均匀；密度场应多尺度变化 |
| 非均匀点过程／簇过程 | 稀疏孤山与集中峰群的布局 | 地貌占据和密度条件图 | 分布统计可控，但不会直接产生真实山体 |
| Delaunay / 图邻接 | 区域邻接、通行走廊和流域关系 | 条件图规划与边界协调 | 最短图边不等于自然河道 |
| 样条、Bezier、B-spline | 表示断裂线、山脊、河道的粗路径 | 几何约束 | 统一曲率、固定间距会人为感明显 |
| RBF / thin-plate spline | 稀疏高度或坡度控制点插值 | 低频高程条件 | 过冲、过度光滑与远距离影响需限制 |
| FFT 谱合成／各向异性随机场 | 控制方向性和波长分布 | 粗构造条件、岩性场；也用于测量规则性 | 周期边界明显；频谱相似不代表地貌相似 |
| Wavelet / Laplacian pyramid | 分离大尺度布局与小尺度细节 | 条件、残差约束、多尺度比较 | 高频细节不能补回模型缺失的主体结构 |
| Gabor noise | 局部控制方向性与频率 | 节理、岩层表面细节 | 更适合微结构，不适合独立生成大陆与水系 |
| Diamond-square / midpoint displacement | 传统分形高度图 | 对照基线；不作为本项目主要候选 | 网格与分形伪影，用户指出的问题容易复现 |

已读取的实现参考：[FastNoiseLite](https://github.com/Auburn/FastNoiseLite)、[GSTools](https://github.com/GeoStat-Framework/GSTools)。[Improving Noise](https://cs.nyu.edu/~perlin/paper445.pdf) 与 [Curl-Noise](https://graphics.pixar.com/library/CurlNoise/paper.pdf) PDF 已保存；本轮不宣称逐页审阅。RBF、样条、FFT、形态学和稀疏求解可从 [SciPy](https://docs.scipy.org/doc/scipy/reference/) 接入。

## 4. 水文、降雨、侵蚀与沉积

| 算法 | 解决问题 | 建议用途 | 特别注意 |
|---|---|---|---|
| D8 | 每格选择最陡的一个下游方向 | 便宜的汇流基线与测试工具 | 八方向偏置；平地与洼地需处理 |
| D∞ | 连续方向分流到邻接格 | 减弱网格方向偏置 | 有限栅格近似；不等于完整浅水动力学 |
| MFD 多流向 | 水向多个较低邻居分配 | 坡面径流与汇水面积 | 容易过度分散，不一定形成清晰主河槽 |
| Priority-Flood | 填洼、确定溢流高程／流域出口 | 修正扩散 DEM 的意外封闭洼地 | 不能把设计湖泊、喀斯特洼地和天坑全部填掉 |
| Depression breaching | 切开洼地出口 | 避免大面积填平地形 | 切槽可能破坏标志景观，应设置代价与最大切深 |
| 流量累积与 Strahler 等级 | 流域层级、干支流规模 | 河宽、切深、河岸材质 | 应累积空间降雨与入渗后的径流，不能处处单位降雨 |
| Stream Power Law | 河流下切与抬升竞争 | 扩散地形上的长期地貌修正 | 单位、像素尺度、时间步与岩性系数必须一致 |
| Fastscape 隐式求解 | 高效求解流功率地貌演化 | 低分辨率大流域计算 | 不能只提取公式而忽略流向、边界和沉积条件 |
| SPACE | 基岩侵蚀、沉积层与输沙耦合 | 谷底、沉积盆地、岩性差异 | 比单一切沟复杂；优先离线评估 |
| 粒子／水滴侵蚀 | 局部坡面搬运与沉积 | 限幅的细节修饰 | 容易产生虫纹和过度冲平；大河连通性不能靠它保证 |
| Virtual-pipe／浅水栅格模型 | 水深、通量与侵蚀耦合 | 局部降雨、沟槽与沉积试验 | 水量非负、CFL／稳定性、GPU 同步问题；简化管道不等于完整流体精确求解 |
| Thermal / talus erosion | 陡坡物质向下搬运 | 碎石坡、崖脚堆积 | “thermal”在图形学中常指坡面松弛，不一定是热传导模拟 |
| 线性／非线性 hillslope diffusion | 坡面缓慢蠕动、临界坡度响应 | 风化与坡面演化 | 与生成式扩散模型是不同概念；不可用平滑 PDE 冒充 AI 扩散 |
| 粒子风蚀／盐跃沉积 | 风向控制的侵蚀与沙粒迁移 | 干旱变体、沙丘与局部裸岩 | 干旱地区也有暴雨侵蚀，不能只有风蚀 |
| 河曲迁移 | 根据河道曲率和沿程响应迁移河岸 | 宽阔平原河流 | 随机正弦线不能替代曲率、输沙与截弯机制 |
| DeltaRCM | 简化河流三角洲水沙过程 | 湖盆入口和未来沿海扩展 | 首批四地貌不是必须项；不宜运行在每个区块 |
| 地形抬升／断层位移 | 构造活动对高程的长期作用 | 裂谷粗条件、断崖历史约束 | 可先做空间位移场，不必模拟完整板块运动 |
| 冰川地貌过程 | 冰流与侵蚀、U 形谷等 | 寒冷气候的特定历史地貌 | 当前有雪不意味着历史上受过冰川侵蚀 |
| 溶蚀／反应输运 | 水、化学反应、裂隙扩张 | 喀斯特地下河与洞室组织 | 昂贵；初版应明确采用几何／地质启发式近似 |
| 地形降雨与雨影 | 盛行风、水汽输运、地形抬升 | 区域气候修饰与径流输入 | 仅用局部坡度无法表达上风向水汽耗竭与降水滞后 |

## 5. 导数、向量和更广的数学工具

公式及数值注意事项见 [数学工具箱](数学工具箱.md)。

| 方法 | 对本项目的实际价值 | 推荐程度 |
|---|---|---|
| 梯度、坡度、坡向 | 区分平地与崖壁；计算下坡方向；条件与验收指标 | 必须 |
| 法线、方向导数 | 坡面材质、迎风坡、岩层倾角 | 必须 |
| Hessian、特征值／特征向量 | 检测峰、山脊、谷地、鞍部，分析方向性 | 高 |
| Laplacian、均值曲率 | 坡面变化、曲率约束、受控松弛 | 高；限制平滑强度 |
| 结构张量 | 多尺度山脊方向、连贯性与各向异性 | 高 |
| Poisson / screened Poisson 重建 | 从目标坡度恢复高程，衔接区域边界 | 高；不是水文万能修复器 |
| 各向异性扩散 | 沿岩层平滑、跨断崖少平滑 | 高；与生成式扩散分开命名 |
| 散度、旋度、Helmholtz 分解 | 区分汇流、旋转与无散度扰动 | 中高 |
| Jacobian、行列式与奇异值 | 检查 VDM／坐标扭曲的局部折叠与过度拉伸 | 三维阶段必须 |
| Eikonal / Fast Marching | 距离场、变速传播、洞穴路径代价 | 高 |
| Level set / SDF / CSG | 洞穴、天然桥、天坑与岩棚的实体合成 | 三维阶段必须 |
| 有限差分／有限体积 | 计算导数、守恒输运、离散 PDE | 必须 |
| 稀疏线性系统、CG／多重网格 | 大范围 Poisson、扩散与压力求解 | 按性能需要 |
| 图最短路、最小生成树、连通分量 | 关键洞室连通、河网／流域组织、通行检查 | 高；河流不能随意套 MST |
| 形态学、距离变换、骨架提取、watershed | 平地连通性、山体分割、洞口厚度 | 高 |
| 持久同调／Morse 思路 | 在多阈值下区分真实峰体与噪声，检测过度连山 | 研究候选，避免首版过重 |
| 频谱、自相关、变差函数 | 检测规则间距、方向偏置和缺失尺度 | 高 |
| 自动微分与约束优化 | 将平地、坡度、边界损失传回生成过程 | 模型适配阶段 |
| 最优传输 | 比较或调整地貌属性分布 | 探索项；不能单独保证空间结构自然 |

公开工具参考：[SciPy 稀疏求解](https://docs.scipy.org/doc/scipy/reference/sparse.linalg.html)、[SciPy ndimage](https://docs.scipy.org/doc/scipy/reference/ndimage.html)、[libigl](https://github.com/libigl/libigl)、[Geometry Central](https://github.com/nmwsharp/geometry-central)、[scikit-fmm](https://github.com/scikit-fmm/scikit-fmm)、[GUDHI](https://github.com/GUDHI/gudhi-devel)、[POT](https://github.com/PythonOT/POT)。工具可用不等于已为本项目实现该算法。

## 6. 三维地形与洞穴

| 方法 | 能力 | 与扩散基础地形的连接 |
|---|---|---|
| 三维 Perlin / fBm 阈值 | 自然空腔、局部粗糙度 | 在扩散山体内部限定范围挖空；不是全地形替代生成器 |
| 双噪声等值面交线 | 细长弯曲通道 | 控制分支密度，仍需验证连通与最小宽度 |
| Perlin Worms / 路径扫掠 | 以路径和半径构造可控通道 | 连接洞室、山脚出口、地下河 |
| 图网络＋SDF 胶囊／球体 | 保证关键节点连通、定义大厅 | 将通道图融合成实体空腔；边界做可控扰动 |
| 元胞自动机 | 快速形成复杂洞穴块 | 适合局部体素提案；需处理分块边界和孤立空腔 |
| 断裂／节理网络 | 地层方向约束裂隙与溶蚀通道 | 桂林按岩性和地下水组织；张家界避免薄柱被随意掏空 |
| VDM 表面位移 | 悬挑岩壁、翻卷石层、局部复杂表面 | 在扩散表面选局部补丁，经有效性检查后转体积 |
| SDF / occupancy | 表示洞穴、浮岛、天然桥等拓扑 | 从高程密度构造基础实体，再做三维布尔操作 |
| Sparse voxel / OpenVDB | 存储局部复杂体积 | 只在有三维结构处提高密度；MC 导出不需要全世界致密体素 |
| Marching Cubes / Dual Contouring | 从隐式体积提取网格 | 预览与分析用；Minecraft 实际生成可直接采样方块占据 |
| DeepSDF／神经隐式表示 | 学习连续形状场 | 局部资产／研究候选，不是现成无限洞穴生成模型 |

来源：[OpenVDB](https://github.com/AcademySoftwareFoundation/openvdb)、[DeepSDF](https://github.com/facebookresearch/DeepSDF)、[Text2VDM](https://github.com/HengyuMeng/Text2VDM)。另检索到论文 [Procedural generation of 3D karst caves with speleothems](https://doi.org/10.1016/j.cag.2021.10.002)，本轮只核对题录，不宣称已找到作者代码。

## 7. 四种地貌如何以扩散为基础

以下是待实验设计，不是 Terrain Diffusion 当前自带能力。

| 地貌 | 扩散前的条件 | 扩散模型应承担的形状 | 后续辅助 |
|---|---|---|---|
| 平原孤山 | 大片连通平地掩码、稀疏山体区域、区域高差范围；避免直接画圆锥 | 不对称岩体、真实山脚过渡和山谷细节 | 轻度差异侵蚀、崖脚沉积，保护平地连通 |
| 裂谷 | 断裂走向、谷底范围、两侧非对称高程与分段阶地 | 崖壁破碎度、支谷、山地与谷地关系 | 沿断裂的向量位移、集水与湖盆；不能固定正弦河道 |
| 桂林喀斯特 | 峰林／峰丛密度、盆地、岩性与水系条件 | 非均匀峰形、群峰组合及山脚过渡 | 喀斯特局部溶蚀，地下河、天坑、洞口；需高分辨率数据 |
| 张家界柱群 | 台地残留、节理方向、柱群核心与深谷条件 | 峰墙、残台与柱群自然转换，独立柱体轮廓 | 按节理增强切割、限幅差异侵蚀，局部 VDM 岩棚 |

难点：30 m DEM 对窄柱体、垂直岩壁的记录不足，插值无法恢复缺失形态。若模型训练数据中缺少这类结构，需要高分辨率 DEM、三维资产／扫描或经过核验的合成数据；仅增加侵蚀算法种类不够。

## 9. 研究结论与下一步验收

1. 先建立 **真实扩散输出基线**：固定模型、种子、尺度、采样设置，保存未加工浮点高程和预览。
2. 做四地貌条件实验。每个样本同时保存条件图、原始扩散输出、轻度后处理结果，禁止只展示最后一张图。
3. 对比山体分组、平地比例、坡度／曲率、山脊连通度和频谱，判断问题来自模型还是后处理。
4. 条件控制不足时，再决定地貌分类微调或新的局部条件分支。先做小规模数据验证，不承诺现有模型能仅凭提示词生成四种地貌。
5. 基础结果经过审美确认后，接水系、区域侵蚀和三维地形，最后接入游戏流式生成。

模型下载、缓存、数据、训练产物和报告全部留在当前工作区。正式实现按单一职责拆分；见架构文档。
