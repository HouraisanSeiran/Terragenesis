# 海岸三角洲河口推进｜工程初版

同源 TD 地形、陆架与有限供沙结果：左为继承的 400 等效年，中为再推进，右为 25 小时潮浪事件。黑线是同一 DEM 的 0 m 等高线；横轴 x 向东，纵轴 z 向南。600 m 为栅格间距，绘图不是河宽；色彩为地形示意，不是真实地表覆盖。

小例口门推进约 4.33 km，接陆 43.56 km²；净增厚至少 0.1 m 的连续沉积体跨度 20.303 km，包含水下。大例接陆 55.44 km²、沉积体跨度 20.957 km，同样包含水下。均为假定供流供沙的有限工程情景，不代表完整多叶瓣或百公里三角洲。

来源、参数、坐标、文件哈希和实现快照见 manifest.json 与 implementation-snapshot。大例图只读旧计算，事件 checkpoint 元数据根据保存的形成进度及事件文件哈希恢复；旧阶段历史见工作区 growth-v2-large-history.json。

主端验收与已知限制见 [验收报告](main-growth-v3-release-review.md)。整体覆盖状态为 partial，完整三角洲任务仍进行中。
