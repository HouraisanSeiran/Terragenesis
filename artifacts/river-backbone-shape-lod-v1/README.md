## 距离语义

前向值是每条原子链到其对应简化弦的精确最大值；它给出全折线距离的保守上界，不泛称全线精确Hausdorff。反向用不大于3m的弧长采样，取sample max再加1.5m，作为连续距离上界。sample max本身是下界，不能直接用它认证30m门；保守上界超过30m只表示暂不能认证，不等实测偏移已超限。

## 准确边界

**本次通过的是固定样本的预览/索引层自适应LOD实验，不是地形全保真或任意世界网络拓扑保证。** 分水岭穿越仍not_checked；没有降低DEM分辨率或测试粗DEM求流向；不以本卡证明A/Q守恒、水动力、泥沙或游戏内水体连通。

因此当前可用策略是“原生路径不丢，显示线段在30m预算内自适应收紧”，而不是宣布所有预计算都用15m/30m分辨率。未来若要真正降低大范围路由计算成本，须另外比较粗细地形下的谷地走向、流域、源终点与水量，不沿用本表示层结果。

复跑依赖本工程与现有numpy/shapely；数据与图不是独立地形生成器。原始验收工作目录为`.scratch/river-backbone-precompute-v1/shape-scale-v1/`，主端权威结果为`results-main-final-v1/`和`audit-main-final-v1.json`。
