# 第三阶段：非高度场三维地貌目录与接入门槛

状态：2026-10-21 规划目录，**不是当前 Terrain Diffusion 无限世界已集成能力**。更准确的统称是**非高度场三维地貌**或**体积地貌**：普通高度图对每个水平 `(x,z)` 只有一个地表高度，不能同时表达顶板、悬挑下表面、洞壁与地下空腔。普通河谷加深、山脊或坡面若仍是一点一高，则不属于本阶段核心。主线见 `docs/terrain-diffusion-four-stage-roadmap.md`。

## 候选形态及其真正的三维部分

| 地貌 | 超出高度图之处 | 前置条件与 Python 可交付物 | 待独立验收 |
| --- | --- | --- | --- |
| 天坑、竖井和天窗 | 同一平面坐标出现地表开口、洞壁与更低的底面；可能有悬顶 | 岩体/侵蚀与地下水位历史、洞腔连通图、崩积物存留/溶蚀/搬运来源账，以及TD到体积的边界；不强制每个天坑具有现存暗河 | 开口与底部连通、覆岩/跨度及材料支撑设计约束、网格无自交、边缘不裂；外形不证明自然成因。 |
| 喀斯特溶洞与通道 | 分层洞道、顶板与地下空腔共存 | 可溶岩、包气带/饱水带、地下水位历史与排泄基准面共同约束；材料仅合成厚度时只声明原型 | 水路、材料层及洞段衔接；按所选地下水机制验形态，不将所有洞道强制水平或竖直。 |
| 地下暗河与地表复出 | 水位、洞壁、覆岩和河床在同一 `(x,z)` 占多层 | 阶段一水量/出口 + 地下通道图 + 材料渗透性/地下水状态与地表交换接口 | 潜入/汇流/复出、水量收支、压力/自由水面及能量损失；依据边界总水头，不以洞底单调下降或潜入点床高高于泉口代替水力验证。 |
| 河谷悬挑和外凸岩壁 | 河谷侧壁回折，局部上部悬于下部之上 | TD河床与岩体共边、材料层序/节理和支撑；侧蚀型另绑定曲率、流向和岸侧水流，非水流风化型另列机制 | 厚度/跨度/支撑、倒挂面、截面与相邻衔接；不默认两岸对称开挖，也不把凹岸视为所有悬挑的唯一来源。 |
| 天然桥、岩拱 | 桥下可穿越的空腔和连通顶板 | 水道穿越/旧洞顶残留型与非水道差异风化型分别声明成因、材料和水文条件，保留双侧拼接 | 间隙可穿越、桥体不自交/两端接地、跨度与支撑约束；不能仅凭相同布尔外形混称自然桥与岩拱。 |
| 石柱群与节理壁面 | 独立柱体侧壁、外凸帽与凹龛，多值表面 | 已有柱群离线网格/预览可复用，加入材质、区域选址及 TD 接缝 | 闭合网格、柱壁几何与不规则截面、相邻生成顺序一致；离线预览不算世界接线。 |
| 深切峡谷的壁洞/上覆层 | 仅峡谷加深可用高度场，只有悬壁、壁洞或交叠岩层需体积表示 | 高度场河谷与局部体积构造的统一拼接 | 断面多值、河床连续、水路和壁洞拓扑均正确。 |

## 统一接入契约（拟制定，尚未认证）

- **表示与所有权**：为每个局部三维体定义世界坐标、材料/空腔语义、几何网格或体素表示、与 TD 原始高度及已发布河床的优先级；边界裁定不能依赖加载顺序。
- **可查询范围与边缘**：给出影响半径、相邻瓦片查询方式、重叠区域去重与缺覆盖时的拒绝；既有原型若只在离线有限窗口工作，必须单独登记。
- **结构和水路**：检查闭合/可定向、非自交、覆岩厚度与连通性；厚度结合跨度、材料强度/节理和支撑判据，未算岩石力学时仅声明设计约束、不认证安全。地表/地下水耦合独立核对总水头、交换和收支，不能拿图片替代拓扑。
- **离散可表示性**：第四阶段仍后置；预留按实际米—方块比例、体素化算法/方向和连通规则检查薄壁/洞顶、洞口与微坡水面台阶的接口。固定厚跨比或3 m阈值不是通用安全/拓扑证明，不足分辨率须拒绝或细化。
- **验收三级**：①局部算法/单元规则可算 ②指定种子同坐标与 TD 基底及邻瓦片的联合结果 ③目标世界消费者实际读取；每档附最小/最大尺度与性能预算。

## 当前基线与下一步

已有离线几何和预览：`docs/special-terrain-offline-20261019.md`、`docs/special-terrain-pillars-3d-20261020.md`；地下水道早期限制见 `docs/underground-river-v1.md`。它们不能证明无限世界版本已有地质材料、跨窗拼接或洞道水力。下一步先选一类已有离线形态，以固定种子和重叠瓦片做 TD 拼接契约与独立拓扑/水路验收，再逐类扩展；不得把整张高度图改名为三维地貌。
