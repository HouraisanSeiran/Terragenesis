# 独立移动雨团切片 v1

写集仅新 `mountain_storm_forcing.py`、对应 tests/verify 工具、本说明和 `verification/mountain-storm-forcing/`。不修改A-v3 source/coupling、B几何、旧证据、TODO/issues/Sonnet；不启动GPU。

## 参数与资源

首例固定pressure完整贡献组1378，四个30m离散湖格和真实河库路径，面积674100m²。峰值24mm/h、σ300m、恒速x向±0.1m/s（360m/h），6–18h有效。起点由同一绝对域中心在x方向对称偏移2160m，雨团在12h经过中心。72h时间跨度，dt900s、288时段，湿土初态135mm。两方向同一几何、HRU、土壤与湖weir参数；不声称实测天气、预测、完整流域或自然湖。

最多250000源格、256HRU、1344时段、50000000个空间样点求值、估计128MiB峰值；逐时段归约，不分配T×源格数组。空间每格等面积；HRU权重由唯一cell_owner格数×spacing²产生，不使用HRU平均高程代替位置，也不按窗口归一化。

## 数学与精度

空间高斯 `peak*exp(-distance²/(2*sigma²))`；中心按绝对米制x东/z南和物理秒移动。时间窗采用高斯沿移动轨迹的erf解析积分，正负尾部用erfc减差减轻消减误差；区间和有效期相交后除以完整时段长度，不是端点瞬时雨。静止/均匀模式分别有闭式公式。有效期是给定box，不是可推断气候。

极低非零速度下erf/erfc差仍会消减。当时段位移/σ<1e-5时使用4点Gauss-Legendre积分；1e-8至1e-14m/s与20000时间中点数值积分对照误差≤1e-12。不是把极低速度直接当静止。

两向使用相同空间轨迹反向行进，因此每格及每HRU累计雨理论相等、有效期内时序反转；报告保存实际差值，不用每窗口归一化制造相等。湿土初始释放可能主导全程峰，另做完全同初态无雨基线，保存6–18h窗口增量峰、6h之后响应增量峰及相对面积平均雨峰滞后。增量是两次非线性模拟的差，不能称线性叠加或观测事件分离。

空间首版30m格中心近似。显式 `spatial_subsamples=2/4` 为等面积子格中点积分，用作精度对照；不改变原地形。窗口拆分按格面积汇总一致（浮点归约允许1e-13级误差），加载顺序不能改变函数。解析时段积分应与拆半时段及高精度数值积分一致。

## 保存与消费

`generate_forcing`保存实际HRU雨强、T+1绝对时间边、唯一owner/count/area及参数，绑定全source identity与独立selection identity。`load_forcing`要求外部可信包SHA与HRU/source/selection，不重新生成天气；身份与范围/面积/时段静态校验不能独立证明生成正确，生成正确性由独立数学测试和源验证器检查。

冻结coupling的surface模式使用固定湖footprint直降雨并从土地面积扣除；移动雨团先面积平均成HRU再由coupling分配，湖格会得到其HRU平均雨，而非该格局地雨值。首例采用足够细唯一格HRU不可超过256，因此这一空间聚合误差必须通过分区说明/子格及格雨对照明确披露，不暗称精确动态水面天气。湖蒸发取0，土壤示意ET仍沿用原值。

消费另目录保存coupling NPZ、weather NPZ、只读JSON/图与审查页，source/coupling冻结文件SHA前后核查。T+1状态与前一T时段量明确对齐，参数与方向分别显示。最终报告比较总雨、峰外流/峰时、最高湖位/末储水与空间近似误差，不因不同总雨把方向效应声称为纯路由效应。
