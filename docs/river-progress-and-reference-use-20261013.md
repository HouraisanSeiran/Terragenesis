## Nucleation与悬挑的后续位置

用户随后明确指向 [Schem-at/Nucleation](https://github.com/Schem-at/Nucleation)。原链接尾部混入“。源码、Issue”，已按实际仓库核对。它与现有任务书里的河源/支流萌生术语无关。

2026-10-13实际读取官方README及提交 `51de345adce496c34e73a6458b2a2d107a1148c2` 的 [SDFs, terrain, and fields](https://github.com/Schem-at/Nucleation/blob/51de345adce496c34e73a6458b2a2d107a1148c2/docs/features/sdf-and-fields.md)。README将其定义为Rust编写的Minecraft schematic引擎，提供构建、网格化、渲染及多语言接口；SDF指南明确提供形体并集/交集/减法、平滑布尔、空间变换、三维标量场及有界体素采样。这是官方文档级核实；本轮未审查其完整源码/Issue，未安装或执行它的示例与测试。

用户建议的“灰度图河网之后再做特殊地貌”适合将它作为局部三维几何与导出候选。工程应用建议为：

1. 保留TD高度图和已生成河网作为大尺度基础，读取河床、岸线、流量、材料与允许修改范围。
2. 仅在选定河岸/岩壁走廊构造三维实体，以SDF减法形成局部掏蚀，以组合形体保留岩棚或石拱。形体位置、尺寸和材料规律由本工程提供，不是该库自动生成的自然过程。
3. 将细节转换为局部体素或网格，和未修改地形衔接；按真实几何变化记录材料，必要时重验河床、水流和水文域边界。
4. Minecraft的方块、schematic与格式转换放在消费适配层，避免反过来定义核心米制水文模型。

单值高度图无法表示岩棚上下两个表面，三维体积表示可以表达它们；这说明Nucleation的工具类别与悬挑需求相符，尚不证明自然度、岩体稳定、性能或本项目集成已经通过。其文档要求显式有限采样范围，并给出单次体素采样工作量限制，因此候选用途是局部地貌处理，不能据此宣称它直接解决无限水文地图。

采用程度记录为“已查阅官方文档，列为后续局部三维几何/消费适配候选，未集成”。已有的[多层高度图三维侵蚀研究](../research/长期维护与三维河网设计.md)可为侧蚀与支撑机制提供另一路参考，不能把它与Nucleation混为同一方法。本轮不实现特殊地貌，也不改动正在验证的河床算法。
