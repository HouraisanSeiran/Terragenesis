## 当前测试版 0.6.0

安装包：build/libs/RemoteMountains-26.3-0.6.0.jar。自定义新世界高度范围为 Y=-64..1023（上边界 1024），海平面按用户指定保持 Y=62。

地貌水平尺寸放大 3 倍；海平面以上相对起伏放大 3 倍。旧算法内部 Y=72 对应新世界 Y=62，即地上高度为 `62 + 3 × (旧高度 - 72)`。海底只平移 10 格，不扩大深度。VDM 三维网格、悬挑、侵蚀细节及地上洞穴随地貌变化；树木、建筑和生物保持游戏尺度。原版矿物分布未专门重做，不应视为完整的高海拔生存平衡。

请替换实例中的旧 JAR 并新建世界，旧存档维持旧高度与配方。游戏实例日志当前仍加载 0.3.0，这是另外两个岩壁样点看不到的原因；诊断见 verification/installation-20260927-latest/诊断说明.md。

新有限演示传送点（先用创造飞行，再下降查看）：

| 地貌/样点 | 命令 |
|---|---|
| 孤山 | `/tp @s 0 850 0` |
| 裂谷与垂直岩壁 | `/tp @s 1536 850 0` |
| 喀斯特与悬挑岩壁 | `/tp @s 0 850 1536` |
| 石柱群 | `/tp @s 1536 850 1536` |
| 76° 斜壁 | `/tp @s 768 850 768` |

有限样片边界扩展为 X/Z=-768..2304；下界与末地仍为原版。下面旧版本的坐标、截图和记录保留作为历史说明，以本节新坐标为准。全域预设同样采用新尺度，仍需启动模型服务。

Minecraft Java 26.3 / Fabric 0.19.5+，Java 25。0.5.0 提供有限演示和全域实时扩散两个预设。

当前路线：**Terrain Diffusion 基础地形 → 世界坐标 XYZ VDM → 专用悬崖塑形 → 三维密度/洞穴 → Minecraft 方块**。

基础生成器未来可以替换；直接输出 XYZ 的扩散网络保留为历史实验，不是当前实际生成路线。

## 先看到模组效果

模组注册两个自定义世界类型，**不会自动替换普通世界的生成器**。

1. 安装 build/libs/RemoteMountains-26.3-0.5.0.jar 和对应 26.3 的 Fabric API；同一实例只保留一份 RemoteMountains 模组。
2. 新建创造测试世界，在世界类型中选择 **长垣 · 地貌世界（有限演示）**，并允许命令。
3. 进入后输入 /tp @s 256 300 256，查看下方的悬崖。
4. 若仍是原版地形，用 tools/diagnose_installation.py 读取存档设置确认生成器；正确类型为 remotemountains:landforms。

“长垣 · 地貌世界（有限演示）”保留内置样片，并在四个象限加入四个地貌测试区：平原孤山、东非大裂谷、桂林喀斯特和张家界石柱群。

| 测试区 | 传送命令 |
|---|---|
| 平原孤山 | `/tp @s 0 310 0` |
| 裂谷 | `/tp @s 512 310 0` |
| 喀斯特峰群 | `/tp @s 0 310 512` |
| 石柱群 | `/tp @s 512 310 512` |
| Voronoi 岩壁与贴壁侵蚀 | `/tp @s 256 300 256` |

四个测试区是在真实扩散样片上叠加的第一版程序化塑形，尚未具备各自专属的完整侵蚀过程。查看地表采样预览：[有限地貌区](verification/demo-landforms/height-preview.png)（不是游戏截图）。旧存档继续使用保存的旧规则；请新建世界查看新增测试区。

“长垣 · 全域地貌世界”按主世界坐标连续请求 Terrain Diffusion 瓦片，不使用有限样片的方形边界。使用前启动工作区内模型服务：

```powershell
runtime/venv/Scripts/python.exe -B -m diffusion --device cuda
```

然后新建世界并选择“长垣 · 全域地貌世界”。该预设需要服务在线；服务不可用时会明确报错，不会回退到有限样片。

全域专用服务器使用 `level-type=remotemountains:global_landforms`。这里只改变主世界，下界和末地沿用原版。实时推理会增加新区块加载时间。0.5.0 按区域放置局部岩壁，完整四类特色山形仍未全域铺开；没有固定样片边界不代表整个世界都没有海洋。

真实模型的相邻瓦片边缘存在微小数值差异；本次采样测得最大约 0.04 方块（原始高程 1.20 米），不是逐值一致。报告见 verification/presets-global/tile-edges.json。

专用服务器在新建存档前设置 level-type=remotemountains:landforms。已存在的原版存档不会因安装模组自动切换。

本次用户实例的检查结果和详细步骤：[安装诊断](verification/installation-20260927/诊断与测试说明.md)。

## 区域岩壁（0.5.0）

全域新增按种子和地貌区域布置的岩壁，各区域采用不同倾角和朝向。跳过低于 96 或高于 265 的候选地表，部分喀斯特区域生成悬挑壁。每个局部面片独立进行 Voronoi 岩块与贴壁侵蚀，跨区块共用最多 12 个面片缓存。完整区域水系、崩塌与堆积仍未实现。

新建有限演示世界可比较三种基准岩壁：

| 类型 | 传送命令 |
|---|---|
| 76° 斜壁 | `/tp @s 256 300 256` |
| 90° 垂直壁 | `/tp @s 512 310 0` |
| 68° 悬挑壁 | `/tp @s 0 310 512` |

角度相对水平面，悬挑采用反向倾斜；基础地形和侵蚀会改变最终局部角度。[实际 Java 网格侵蚀前后对照](preview/regional-cliffs/comparison.png)不是游戏截图。新世界使用 v3 配方，已有存档保持原配方。种子 20260927 的全域验证岩壁位于约 (6698,8959)。

## 第一版实际包含什么

- 默认 JAR 内置真实预训练 Terrain Diffusion 推理得到的基础样片，无需另起模型服务。
- 样片范围为 X、Z 各 -256 到 768，外围 64 方块渐变至海洋；范围外是海床，不是无限扩散地形。
- 悬崖在 (256,256) 附近，使用 76° 可倾斜岩壁、非均匀 Voronoi 岩块、沿面贴壁径流、横向侧蚀和 VDM 写回。
- 洞穴由独立三维噪声密度处理；不能把洞穴全部归因于 VDM。
- 默认基础样片在不同世界种子下相同；区域标签和洞穴等仍可随种子变化。
- 有限演示样片已加入四种地貌测试区；全域版本使用连续扩散基础地形并沿用 VDM/岩壁流程。
- 当前算法配方为 diffusion-vdm-voronoi-runoff-v2；它是有限局部岩壁实验，不是完整地质水动力模拟。
