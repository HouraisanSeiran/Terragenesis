# 分汊河流水面接线：机制初版

河床略高于海平面时，河流现可按自身水面继续输水输沙。共享节点使用同一水面；高障碍支流关闭后，仅在所属分叉内重分配，其他分组份额保留。主端独立23项相关测试通过，嵌套分叉与保存续算已检查。

同源TD原生30m、计算600m，固定种子20261020，X东Z南。01是实际保存床面和路线，底色海岸按平均海位；河网线不表示实际河宽或整格已淹没。02为末态床面/水面剖面，03为25小时床变。原始TD/base未改，原陆地最大床变约0.616mm。

本例输入Q3000m³/s、固体1.6m³/s，明确假定上游水位上限3m（非实测）、糙率0.035。末态五支总接收109.631m³/s，最小河水深1.389m。不能声称3000m³/s情景已全部通流。

25小时实际接收水9908715.838m³、固体5284.648m³；另有水260091284.162m³、固体138715.352m³显式待交付。含待交付固体残差0.000000477m³，节点Q残差7.11e-15m³/s。未知记录保持，物理时间推进90000s、等效年不变，末态水面冷读重算一致。

这是游戏用途的准稳态矩形河槽近似，当前按显式水头上限缩减固定分流比例，并未求完整回水、河道蓄水或漫溢。河道库存当步同址保护时不参与海洋混合；其余海洋湿干处理与浮点限幅警告见实现报告，最终库存有限且收支闭合。

下一步复用实际同源上游断面、河宽/水位与水沙输入，再接有限漫滩及分汊间平原。完整三角洲未完成，百公里继续暂缓；默认世界未接线。来源、代码快照和详细验收见manifest及数据目录。
