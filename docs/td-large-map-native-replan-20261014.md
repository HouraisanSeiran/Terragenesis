# 38.4km TD 原生汇水重规划：移除粗标签矩形截河

用户图审发现上一版河网沿规则粗域标签形成正方形边界。复现显示 64 个内部端口集中在原生列 723、390 等位置，且不在 TD 瓦片接缝；根因是把 10km 粗规划标签当成了不可跨越的分水岭。

本版使用 `native-source-replan`：在固定的 1280²、30m、38.4km TD 支持范围内直接依据原生 TD 排水图和 4m 浅洼工作面重算。旧粗标签保留为诊断参考，不再生成路由墙或内部出口。原 TD、旧计划及 02 产物均未覆盖。
