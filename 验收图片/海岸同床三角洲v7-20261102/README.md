主端独立核查来源、实际床面、低地面积、通道与河口、全部库存及外海出口。最大短期抬床约1–1.5mm、下切约4.4mm；未再次发生世纪悬沙集中沉降或平原瞬间消失。21项海洋/三角洲相关测试通过。[详细验收](main-delta-v7-review.md)。

固定种子20261020，实际网格600m，原TD来源30m；图像清晰度不代表30m计算。水沙量为明确情景，不是当地观测。地质期采用连通路径和0.02m/s假设输送速度结算出域，短期侵蚀只作用于暴露的0.1m活动层。长期高水位+1m允许新生低地继续接收有限沉积；原陆地不作宏观改写。

限制：现阶段分汊拓扑为构造网络，600m河槽与分析河宽分开；陆侧+6.65m源床未开挖，当前接的是海侧水沙端口。海底输送尾段不都属于浅河槽。400年有2处贴岸口门，800年3处。实际范围约十余公里，连续叶瓣切换、百公里级证据和完整上游湿床连接仍未完成。来源、文件摘要及实现快照见manifest.json。
