# 三角洲沉积叶瓣与口门演化

已完成有限域三角洲构造链验收：沿用原TD、床面与泥沙库存，复用非规则河流内核，在原有两条动态新增分汊基础上续算2等效年，再追加25小时周期潮浪。代码相关回归111项通过，四阶段独立冷读8项通过。自然形态供用户验收。

![同源床面与沉积叶瓣](01-床面与沉积叶瓣.png)

海侧实际出现两个主要水下沉积体：两年床升超过1cm的面积分别为1.64和0.88km²，峰值0.544和0.208m；三个口门实际移动约703、308和376m。相邻口门沉积体可以合并，包含历史库存的再搬运。图中细线、床变和水深均来自保存数据。

![海侧床变](02-海侧床变.png)

![同床潮位](03-同床潮位.png)

同一最终床面下，模型低潮仅口2通流，均潮口2/3通流，高潮三口通流。200m网格及相邻海面规则会影响关闭判定，这不是已标定的真实断流结论。图中关闭通道没有画成流水。

## 尺度、来源与物料

- 历史世界种子20261020；来源100×100km、原生TD30m，计算200m；图示窗口X −6.2至1.6km、Z 5至13km，Z向下。100km是来源图幅，当前沉积体为公里量级。
- 材料沉降速度0.001m/s来自工程既有MaterialParameters默认值，为显式同质情景；不是实测粒级，也不是自动推导的上游粒级。原浅大陆架和历史地质床面保持来源记录。
- 上游水头2.2655969241354335m；请求Q150m³/s、固体0.08m³/s，实际交付受水力限制。两年请求固体5,049,216m³，待交付增加4,366,067.863m³，库存加外输增加683,148.137m³。内部交海gross不能再次算外源。最终固体残差约−0.000001201m³。
- 初态formation5.3年、物理190800s；两年末formation7.3年；事件末物理280800s。等效年和物理秒分账。
- 这是地形/实际水深配色与床变专题；未生成植被材质，没有生成式图片或额外美学改形。图01/03显示重新求解的实际湿断面宽度；图02细线只定位河道。统一色阶及阈值见render-settings.json。
