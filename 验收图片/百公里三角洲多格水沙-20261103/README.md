# 百公里三角洲多格水沙验收样例

本轮完成宽河多格库存、年度/物理输沙及口门追岸接线，并修正只看中心格导致的河口误阻断。实际同源百公里样例已完成三场连续库存的25小时潮浪事件；最后一场采用足迹接海和事件末有限追岸，物理时钟累计75小时。**本目录保存数据接线验收快照；用户指出直角分汊，当前河网自然形态未通过，整体目标继续。**

![区域主图](01-区域主图.png)

- 共同成因的连通厚沉积体约 **107.3 × 50.6 km**，面积 3676.68 km²。定义为相对派生陆架厚度超过1m的连通沉积，包含湿河槽及水下叶瓣。
- 平均海位总出露 **2904.84 km²**；河道把陆地分成数块，最大单块 1853.28 km²。不能把整个沉积体都称为一块连续陆地。
- 高于+0.3m面积 2885.04 km²。低/均/高潮重新求解的实际水路见主端JSON，不凭拓扑线认定通水。
- 本例网格 **600m**，原始TD30m。宽河另存多格细断面；有效宽度约 546–2166m。30m局部演化、细潮沟未验收。

## 数据与复用

[dem.npz](dem.npz) 提供格平均床面、有效域、原未知域、平均海位连通海洋及世界坐标。`state.npz` 与 `state.json` 是完整配对存档；用 `coastal_delta_evolution.load(prefix)` 冷读。河网实际XZ、细槽床、水位与库存语义详见[接口交接](interface-handoff.md)。这些文件采用米制XZ坐标、行Z列X，海平面基准0m。

来源产品仍在 `../../.scratch/delta-hundred-km-20261103/wide-shelf/product`，不复制大体量TD。历史种子20261020，原始TD及板块身份未修改。新的正式世界按CONTRIBUTING中的种子约定另建来源。

## 验收与限制

主端已通过库存、保存续算、接海、有限追岸及宽度一致性相关测试，见[工程审查](main-engineering-review.md)。[独立核查](main-final-accept.json)检查共同库存、实际槽床、来源、河口与沉积体尺寸；[最后一场事件报告](mouth-extension-v3-case-report.json)记录水沙及实际追岸。最后25小时实际供水1350000000m³、新固体1800000m³，固体总账残差0.000000m³，未分配地质库存不动。内部交海gross含继承库存/再搬运，不能计作新供沙。

最后一轮准备、事件及诊断合计445.2s，本轮未单独记录RSS；首场25h终点RSS约83MiB，非峰值，不使用GPU。性能与世界扩展边界见[逐项评价](world-scope-review.md)。

1125等效年是未标定的地质构造参数；四口初态是多级构造分叉，不冒称四次自发改道。平原仍偏平滑，部分河道较直；数值混合程度会明显影响形成面积。本例物理步内固定既有平面足迹，步末显式有限追岸新增短槽，未实现连续横向岸蚀；默认400m漫滩范围小于600m格距，本例漫滩交换为零。河道物理步为有限携沙/侵蚀，河床沉降由年度近似处理，海洋沉降由物理步处理。上游水沙为大流域情景，混合粒径、跨区/多尺度、默认世界和前端未验。

千年稳定、细潮沟和成熟自然美学不能由三场25h事件证明，旧形态任务09继续保留；本次交付完成百公里工程样例及其数据接线。
