# 自适应分汊与陆侧扇面验收

日期：2026-10-18

本轮完成了河口三角洲任务 10。最终场景为 [scene15](../.scratch/hydrological-planning-domain/coast-bounded-mouth-16km-20261017-15/scene.npz)，由冻结的原始风格化河口场景独立重建。场景尺寸为 16 km × 16 km，栅格为 800 × 800、20 m。原始场景输入和上游有限水沙包没有被修改。

## 几何结果

算法从六个候选中选出五个终端河道：四个一级支汊和一个从终端 0 陆侧前缀分出的二级支汊。终端父索引为 `[-1, 0, -1, -1, -1]`，层级为 `[0, 1, 0, 0, 0]`，宽度为 170、102、120、105、90 m。二级支汊宽度小于父支汊，且其起点床面与父河段插值床面一致。六个候选的分数、选择状态、原始父索引与过滤后的父索引均写入 `candidate_selection_json`。

每条路径均通过密集采样检查：只有最后一个路径样本进入开放海域。最终场景的海洋河槽切方和河槽海洋重叠均为零；来流、主干和所有终端属于同一 D4 湿连通分量。保留上游床面逐数组不变。

扇面构造参数已同步扩大到名义半径 7,600 m、侧向半宽 4,500 m，并写入 `fan_parameters`、`fan_radius_m`、`fan_angle_rad`、`fan_outer_radius_m` 和 `platform_weight`。相对已接受的 scene02，有效扇面面积（平台权重大于 0.5）由 34.4432 km² 增至 52.9904 km²；原有陆地上的平台面积由 10.4276 km² 增至 14.2892 km²。低地起伏与平原改造仍是独立施工预算。

## 动态水沙结果

`metric_integrated_delta.py` 现在支持显式父子树。共享父河段只路由一次；内部节点以当前床面的 Manning 阻力共同求解水头和分流，床变后每月重新求解。泥沙按同一拓扑递归分配，零水月份进入 escrow，后续有水时释放。运行器和审计保存任意固定终端数的数值矩阵、节点水头、每端出口量和冷重放数据，同时保留旧三支 fixture 的兼容入口。

41 项聚焦测试通过，覆盖 1、2、3、4、5 终端、真实父子次级分支、正供沙床变、零水暂存、动态分流、海岸终止、扇面选择和来源保持。

## 边界

这是基于现有河流数据的风格化构造和有限供沙反馈模型。大范围可见平原主要来自明确记账的施工几何，不是 31,102 m³ 年供沙自然长成；本年度没有形成新的干地。模型仍没有完整二维海岸羽流、潮汐/波浪、长期自主袭夺或袭夺、以及 Terrain Diffusion 联动。海域只接收首次入海后的泥沙外排，不继续生成虚构河槽。
