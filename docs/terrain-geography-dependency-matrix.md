## 共用规则

无限平面优先使用由 `(seed,x,z)` 确定的多尺度背景，再由当地海陆、地形、材料、水和生态关系修正；不预设地球经纬度、极昼/极夜或完整全球环流。每个候选在实施前分别声明：空间/时间尺度、输入字段和单位、确定性及最远依赖范围、缺输入时的拒绝行为、产物身份、耗时预算、默认消费者。验收分开报告规则可算、同坐标联合观测和生产消费；预览图或分类可达不能替代后两项。气候与水文可反馈，但每次新增耦合均须留有来源、版本和回归证据。

## 分批落地门槛

1. **定义而非抢先贴标签**：逐项写清理想观测场景、输入单位、输出、依赖范围与缺依赖拒绝；气压带/洋流/板块是否采用应按景观收益与成本单独裁定。
2. **打通必要链路**：优先核查阶段一河网的水量/出口，再决定 v1/v2 季节水文接线；同时区分材料厚度、土壤层与水桶。
3. **联合验收**：在指定种子与世界坐标对比地形、气候、水、材料和生态的实际联合输出，并单列默认消费者状态。不得从单模块测试推断全工程通过。
