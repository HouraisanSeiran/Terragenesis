# 三角洲漫滩沉积与平原微地形：有限库存与蓄水复用审计

日期：2026-11-08。任务边界：支持 `.scratch/delta-naturalness-20261108/` 第二阶段；第一阶段输入冻结为 `phase1-r3/{100m,30m}`。本笔记只做原始文献研究和代码只读审计，未修改生产模块、测试或 CLI，未运行新地貌实验。采用 `research` skill；论文启发、论文复现与游戏验收分别记录。

## 可直接交给实施的结论

1. 现在复用 `ChannelInventory` 的有限账户、`overbank_exchange` 的水量总上限／四邻域过岸可达性／指数沉降，并对洪泛接收区使用已有局部守恒重分配核。新增形态应来自有限泥沙的空间分配及床面更新，不叠加无物源的噪声。
2. `overbank_exchange` **没有持续水库存**：报告中漫出水全部返回，局部 `wet_fraction` 随调用结束消失。它也不是完整自然堤模型；BFS 访问次序影响接收位置，没有沿漫滩路径的沉沙耗减或洪水退落。
3. 多格河道的泥沙属于节点 footprint。指定河节点的漫滩供沙要先 `ChannelInventory.take(node, MOBILE, requested)`，再 `commit`。直接扣一个 grid cell 后用 `apply_grid_changes` 回填，会按共享该格的所有节点及 outer 库存同比扣除，不能表达指定 donor。
4. `advance_event_hydraulic` 已把 `accepted_q × dt` 作为水输入交给 marine。再把其中一部分保存为洼地水而不改原输入，就重复使用同一通量。原 marine state 只有累计 `water_input_m3`，没有逐格可支取水量；该累计量不能冒充储水。
5. 推荐选择一个明确接线：在现有物理子步中先分流并给 marine 剩余通量；或另建具有唯一 input id 的有限洪水边界事件，并与第一阶段事件分别记账。先让水／沙源清楚，再讨论自然度幅度。

## 供第二阶段采用的降阶方程

本节是基于固体／水体积守恒与上述过程的**工程推导**，不是论文算法复现。保留现有孔隙率约定，不采用论文中为简化设定的零孔隙率。

### 有限过岸水与有限 donor

对一个物理时间区间只定义一次已接收边界水 `Win = Qaccepted × dt`。所有河段的分流量满足：

```text
sum(Wspill_j) <= exchange_fraction × Win
Mtake_j <= ChannelInventory.amount(node_j, MOBILE)
Mtake_j <= Cmax × Wspill_j
```

`Cmax` 在这里是 **solid_m3 / water_m3**，不是 kg/m³。若输入来自质量浓度，应显式除以固体颗粒密度；不能把 0.01 的固体体积分数当成 0.01 kg/m³。没有移动库存、没有新边界供沙、也没有允许侵蚀的床沙，就不能生成新堤。河槽构造挖方已另列为未安置构造库存，不能隐式转作事件来沙。

### 从沉降到堤—盆地差异

对水深 `h` 内充分混合、没有再悬浮的有限悬沙 `M`，沿用当前精确耗减核：

```text
fsettle = 1 - exp(-ws × tau / max(h, hmin))
Mbed = min(M × fsettle, solid_accommodation)
znew = zold + Mbed / (A × (1 - porosity))
```

浅水、长停留有更强沉降，但沉积不能超过实际悬沙或可容纳体积。未沉降量仍须在 mobile／stranded／下游输出中择一明确保留，不能丢弃；干后停留在 `stranded` 的泥沙不等于已形成地形。

若需要最小自然堤横断面，设过岸路径上 `u`、`h` 为局部代表值，忽略再悬浮，则平流—沉降方程给出长度 `L = u × h / ws`。可按有限路径包的耗减计算：

```text
Msurvive(x) = M0 × exp(-x / L)
Mdeposit([x0,x1]) = M0 × (exp(-x0/L) - exp(-x1/L))
```

距离从**实际河岸**起算，沿越岸后的可达路径，不用到中心线的欧氏距离穿过堤或山。路径分叉先分包，使各包 `M0` 之和不超过 donor；不能每个格都拿同一个 `M0`。这里的常速常深解仅作粗模型：未知二维绕流、植被、扩散和细粒絮凝均保留为限制。若只采用归一化距离权重分配有限泥沙，应标为“过程启发分配”，不能称已经求解该 PDE。

例算仅说明量级：`ws=1e-4 m/s`、`tau=3600 s` 时，`h=1 m` 沉降约 30%，`h=0.1 m` 约 97%；`u=0.05 m/s,h=0.5 m` 对应 `L=250 m`。这些值**不是本场景标定建议**。若固体不足以覆盖平原，接受小幅真实堆积，不用增大幅度补偿物源缺口。

盆地先表示为相对于近河堆积区的低地：给天然可达低地较少沉积，即可与抬高的近岸形成微地形。若需主动挖出洼地，挖出固体必须另有去向；若构造平原原先过平，不能声称单次短洪水已还原其长期地质历史。[Han–Kim 2022；Johnston 等 2019]

### 持续水体和退水

每个非河道可用面积上的 `V_i` 是真正保存量：

```text
Vnew_i = Vold_i + Wspill_i + sum(internal_in) - sum(internal_out) - Wreturn_i - Wexport_i
H_i = bed_i + V_i / A_i
```

每条 D4 面交换只能由高水头 donor 过实际床面／岸坎，且所有流出共享 donor 的 `V_i` 上限。地形降低只增加容水空间；它本身不增加水。地形抬高后保持 `V`，重算水位并有限重分配，不能保持旧水深而额外造水。

若使用汇总盆地，体积—水位关系为 `V(H) = sum(A_i × max(H-z_i,0))`；用保存的 `V` 反求 `H`，而不是按处方 `H` 填满所有低格。已有 `volume_stage` 可反解局部曲线，但块内“共用水位”仅适用于已连通的容量，不能跨封闭堤坎当成一个池子。

全区检查采用 `Vinitial + Win = Vfinal + Wmarine_or_export + Wreturn`；`Wspill` 和格间转移都是内部量，不再作为新源相加。没有实现蒸散、渗漏或海洋补水，就不要在账本里凭空添加这些项。

## 本轮最小可评估证据

优先保留四个外部行为证据即可，不扩大成科研级标定：

- 同一 donor 的总供沙不超 MOBILE，多个河段共享一个有限水边界；共享 grid cell 的无关节点库存不变。
- 干脊阻止跨越，封闭洼地保存有限水，连通低口能退水；零水／零供沙输入不会产生新水／新地形。
- 同域“近实际河岸—远漫滩”剖面、地形差值和真实水量图可同时解释堤—盆地差异；不得只靠渲染色带证明自然度。
- 100m／30m 分别保存孔隙率、可用面积、输入 id、有限水沙总量、结果库存及限制；平面主路径相同不等于微地形已多尺度收敛。跨区接缝、无限域边界与长期潮汐反馈仍属未测。

本笔记不新增参数扫描、模型替换或默认世界接入要求。现在可做的是有限事件下的过程启发微地形；随后在独立潮汐任务中再接收真实储水、双向流和新来源身份。
